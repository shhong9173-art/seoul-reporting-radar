# DART 공급계약 최초/정정 공시 비교 및 기사 색인 검증

## 구성
- `scripts/recent_contracts.py`는 13개 직접 출입처 법인의 최근 21일 DART 공시 접수 목록/정정·원문을 수집합니다. 조회가 실패하면 자료 삭제/0건으로 변경하지 않습니다.
- `scripts/dart_lineage.py`의 *원공시 접수번호가 정정문에 명시된 경우만* 원공시와 정정공시를 같은 계약으로 연결하는 기존 엄격한 조건을 유지합니다. 동일 회사·일자·제목만으로 추정 연결하지 않습니다.
- `scripts/dart_contract_followup.py`가 공식 접수번호·개별 DART URL·날짜를 검사하고, 확인된 두 원문의 동일 항목만 before/after 검토표에 내보냅니다. 금액 증감이나 납품 물량이 실제 사업에 미친 영향은 자동 추정하지 않습니다.
- 기사 검색은 공시 접수번호와 회사/공시 유형의 Google News RSS를 각각 1번(공시당 최대 2회) 조회합니다. 기사 색인은 실제 보도내용이나 동일 계약 여부를 입증하지 않으므로 기사 원문과 직접 대조가 필요합니다.
- 검색결과 0건, RSS 장애, 쿼리 미실행 상태는 모두 구분합니다. 실패하면 '기보도 0건'으로 쓰지 않습니다. 관련 기사 후보가 있더라도 이미 보도된 동일 계약의 증거로 자동 확정하지 않습니다.
- `dart-contract-followup.html`는 최초 공시와 변경 후 값을 나란히 표시하고, 각 RSS 검색어/기사 후보/언론 기사일/검증 질문을 표시합니다. 한 화면의 최우선 목적은 **취재 질문을 구체적으로 줄이는 것**입니다.
- KIPRIS 서비스키·호출량 문제와 무관합니다.

## 2026-10-15 현재 실제 DART 저장 스냅샷의 검증 한계
공급/투자/생산 관련 목록 공시 7건(직접 출입처 13개), 그중 원공시 독립 확인이 되지 않은 정정공시 4건. 나머지 3건은 공시 접수와 문서 읽기까지 기록됐으나 계약 상대방·금액·효력을 자동 추출하지 못했습니다. 공식 원문의 표형식 차이일 수 있지만 **계약 자체가 없거나 금액이 0이라는 뜻은 아닙니다**. 공시 접수 외 새로운 계약 내용과 기보도 확인 없이 단독기사라고 분류하지 않습니다.

## 취재 확인 우선순위
1. 정확한 원공시와 정정공시 연결 여부(명시 접수번호/동일 법인/원문)
2. 계약 금액, 계약 기간, 납품 품목·실제 출하량·해외 공급 물량 중 공식 문서에서 확인된 항목만
3. 당시 기존 공시/기사 제목·전문 및 기업 IR 자료의 동일 사건 중복 확인
4. 출입처 회사에 실제 어떤 금액/물량/가동률/거래 구조 변화가 있었는지 질문
5. 현재 변화와 확인된 대응·영향을 한 문장 기사 야마로 정리한 후 발제

**기사 검색 0건은 미보도 증명이 아닙니다.** 일반 Google 뉴스 색인만으로 전문지, 회사 홍보자료, 이전 DART/별도 거래를 모두 확인했다고 주장하지 않습니다. 초기 실자료는 사용자 취재 확인 전에 단독보고용 제목 자동 생성에 이용하지 않습니다.
