# NTIS 특허 성과검색 — 21개 실측 결과의 제한적 후속 조회

## 공식 수집 근거

2026-10-14 19:19 KST 승인 PC 수집 결과는 검색식 21/21개 정상 완료, 응답행 136개 검토(일부 중복 가능), 검색식별 `TOTALHITS` 합계 10,401건(고유 성과번호 수 아님), 페이지 미확인 검색 12개입니다. 공개 KIPRIS 출원번호가 같은 NTIS 성과 HIT 내 나타난 결과는 첫 페이지에서 0건이었습니다. **0건은 국가R&D 연구성과 자체가 없다는 판정이 아닙니다.**

검색식 12개를 무조건 추가 페이지 조회하면 일부 법인명(현대자동차 3,154건, 포스코 1,751건 등)만 불필요하게 반복 수집됩니다. 확인할 범위를 기자의 기술 취재 목적에 맞춰 줄였습니다.

## 이번 15회 요청의 구성

`digests/ntis_patent_followup_plan_latest.json`은 이전 실제 수집본 `digests/ntis_patent_discovery_pc_latest.json`에 기반한 **출처 시점 고정·검증형 계획**입니다. 새로운 특허 조사서가 생성되더라도 **계획을 자동으로 다른 특허에 붙이지 않습니다.**

- **기술어 추가 페이지 4개 × 2페이지 = 8회:** 부분방전(197건), 메타렌즈(142건), 복합패널(238건), 방열 조성물(127건). 기존 1페이지는 앞선 수집본으로 보존하고 **2·3페이지(시작 위치 11·21)**만 조회합니다. 네 기술 모두 추정 총 결과가 300건 이하입니다.
- **법인명+기술어 7개 × 1페이지 = 7회:** 엘에스전선 부분방전, 현대제철 상변태, 두산에너빌리티 침투탐상, 현대자동차 메타렌즈, 포스코 복합패널, 현대자동차 방열 조성물, 현대모비스 RTCM. 기술어와 법인명은 이전 KIPRIS/NTIS 자료에 나오는 표기만 사용합니다.
- **중복 제거:** 현대자동차 법인명 단독 검색 2회 등 이미 확인한 넓은 기업명 검색을 반복하지 않습니다. 같은 검색어와 페이지 조합이 여러 특허에 걸쳐 중복되면 HTTP 호출은 1회만 실행하고 개별 특허번호를 각각 확인합니다.

**주의:** NTIS 일반 `query`에 회사명과 기술어를 띄어쓰기해 넣는 방식은 공식 서버가 논리적 **AND** 검색을 한다는 의미가 아닙니다. 실제 응답에서 NTIS 성과번호·`RegistType=출원`·KIPRIS 출원번호·`ProjectID`를 각각 확인합니다. 결합검색에서 0건이더라도 성과 부재나 해당 기업 참여 부재를 주장하지 않습니다.

## 등록된 Windows PC에서 실행

두 파일을 **같은 폴더**에 놓거나 검증된 실행 ZIP을 압축 해제합니다.

- `scripts/ntis_patent_followup_pc.ps1`
- `scripts/Run_NTIS_Patent_Followup.cmd`

NTIS에 신청한 공인 IP로 접속하는 Windows PC에서 `Run_NTIS_Patent_Followup.cmd`를 더블클릭합니다. 키는 PowerShell 숨김 입력으로 받고 **NTIS 공식 HTTPS 서버 이외에는 보내지 않습니다**. 명령줄/텍스트파일/출력 JSON에 저장하지 않습니다.

정상 실행 후 같은 폴더에 `ntis_patent_followup_pc_latest.json`이 생성됩니다. 메모장으로 비밀키나 비공개 정보를 포함하지 않는지 검토한 뒤 해당 JSON **파일만** 이 대화에 첨부합니다.

이 프로그램은 최대 **11개 고유 검색계획, 15회 HTTP 요청**으로 종료합니다. 사이트 오류·권한 문제·페이지 이동에 따라 중간 종료 시 오류 코드와 조회한 범위를 분리합니다. 페이징 중 `TOTALHITS` 값이 크게 달라졌거나 페이지 범위에서 응답이 없으면 정상 0건으로 처리하지 않고 조회 오류로 기록합니다.

## 취재 검증과 실무 주의

성과 HIT의 `RegistType=출원`(01), 해당 KIPRIS 출원번호, `ProjectID`가 일치한 레코드만 제한적으로 결과 파일에 남깁니다. 이전 NTIS 과제검색 26개 고유번호는 **일부 표본**이므로 여기 없는 `ProjectID`를 발견해도 버리지 않고 **후속 확인용 번호**로 남깁니다. 이는 해당 국가과제의 실제 수행기관·특허의 제품 적용·양산·미보도 단독을 입증하지 않습니다.

이 수집계획의 원래 특허 조사서가 갱신됐으므로 **2026-10-14 원천 시점의 후속 조사**라는 점을 항상 함께 표시해야 합니다. 부장 발제에 바로 올리지 말고 NTIS 성과·과제 원문, 법인 참여, 언론 기보도, 신규성 및 회사 답변을 따로 확인해야 합니다.
