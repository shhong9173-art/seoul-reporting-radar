# DART 정정 공시의 과거/현재 기재값 단계적 비교 (2026-10-16)

기존 정정공시 추적은 해당 회사·공시 유형·정정문 참고일자가 겹친 과거 DART 문서를 확보했으나 **동일 계약의 독립 식별은 검증되지 않았다**. 과거 문헌의 정정표에서 '정정 전→정정 후' 값과 이번 정정문의 '정정 전→정정 후' 값을 나란히 보여줘 사람이 계약 관계를 검토하게 개선한다.

- 과거 후보 공시가 **정정문**일 때는 발행사 표 내부의 해당 필드 정정 전·후 값을 근거로 표시한다. 예: 과거 후보 3000억원→3723억원, 이번 정정문 3723억원→3833억원. 단, **같은 계약의 연속 변경이라고 기재하지 않는다.**
- 과거 문헌이 **원공시**이면 원문 명시 계약 조건만 비교한다.
- 과거 후보 문서에 '원공시 접수번호' 등 명시적으로 라벨이 붙은 **다른 접수번호**가 있을 때만 '더 이전 원문 참고 단서'로 기록한다. 해당 후보 원문에 명시돼도 발행회사 목록으로 해당 번호/유형/법인 식별을 추가 검증하지 않았으면 verified origin으로 표시하지 않는다. 이번 정정과 그 접수번호 사이의 계약 동질성은 **false**다.
- 숫자가 일치하는 것만으로 동일 계약·사업 수주·변경 효과·최초 보도·단독을 확정하지 않는다.
- 부서 문의는 공개 가능한 원공시 접수번호, 과거 정정 이력, 확정된 계약기재값 등으로 제한한다.
- 승인된 기존 OpenDART API만 사용하며 추가 API 자격이나 비공개 데이터 수집 없음.

기존 실데이터 보존 및 CI에서 Python/Node 회귀검증 후 병합한 다음 운영 digests/dart_correction_history_latest.json를 재생성한다. 외부 전자공시 원문에 명시된 신규 라벨이 없으면 더 이전 접수번호는 만들지 않는다.
