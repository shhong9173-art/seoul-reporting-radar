# 자동차·철강 [단독] 기사 원자료 역추적 절차

## 목적
`매의눈·유통`과 비교한 2026-10-18 외부 평가에서 도출된 최우선 개선 과제입니다. 산업 담당 경쟁지의 실제 [단독] 기사 300~400편을 *사후 역추적*해 기사 속 취재 사실이 보도 전에 공식 원자료로 확인 가능한지 평가합니다. 기존 매의눈의 식품·유통 유형별 적중률을 자동차·철강으로 그대로 이식하지 않습니다.

### 수집 범위와 한계
- `digests/press_coverage_index_latest.json`에는 관측된 국내 기사 제목·매체·게시일·기업명이 **수집됐을 때만** 남습니다. 첫 실행은 기준선이며 기사 전문, 경제지 지면 DB, 네이버 뉴스 전체를 대표하지 않습니다.
- `scripts/exclusive_reverse_trace.py`는 제목 맨 앞에 `[단독]` (또는 동등 표기)이 있는 기사 중 취재대상 기업 기사만 후보로 만듭니다. 다른 매체로부터 실제 단독 사실임을 입증하는 기능이 아닙니다. 스포츠팀 동음이의어 등은 제외합니다.
- 자동 발견 후보는 전부 **U (미검증)** 입니다. `Y/P/N`은 자동 지정하지 않습니다. 최소 300~400편의 산업 기사 전문·원자료를 검토한 뒤 원천별 도달률을 계산해야 합니다.

## 사람의 원문 검증 라벨 (Y/P/N/U)
| 코드 | 언제 기록할 수 있나 | 한계 |
|---|---|---|
| Y | 기사 전문에서 최초로 제시된 사실과 *보도 이전 날짜가 확인되는* 1차 원문을 실제 열어 원문 수치·대상·조건을 정확히 대조했다 | 기사 제목만 일치하거나 2차 요약이 같으면 Y 불가 |
| P | 기사의 전조나 부분적 선행 단서는 원문에서 직접 발견했으나 결정적 사실은 원문만으로 얻을 수 없다 | 공개 단서가 전부 기사 내용과 같다고 주장 금지 |
| N | 기사 전문과 관련 공공 원천을 여러 갈래 조사한 뒤 공개 전조를 찾지 못했으며, 사람 취재가 주된 정보원이라는 근거를 기록했다 | 전 세계에 단서가 없었다는 불가능한 증명은 아님 |
| U | 미조사·자료 접근 실패·출처 누락·원문/기사 전문 미열람·날짜 불명확·판정 다툼 | **분모에서 제외**. 데이터 부족을 N으로 바꾸지 않음 |

'업계에 따르면'처럼 비공식 관용 표현은 원자료 존재 여부의 증거가 아닙니다.

## 검증 자료 입력 방법
`data/reverse_trace_verified_labels.json`의 `items`에 사람의 검증 행을 추가합니다. 검증 완료 전에는 빈 배열 그대로 두십시오. 판정에 사용되는 필수 필드:

```json
{
  "articleId": "24-character-index-sha",
  "reviewedByHuman": true,
  "reviewer": "검토 기자 식별명",
  "reviewedAt": "2026-10-18T22:00:00+09:00",
  "articleFulltextReviewed": true,
  "verdict": "P",
  "evidenceReason": "해당 기사 문장/원문 쪽수 및 날짜를 교차 대조한 구체적 메모 (12자 이상)",
  "primarySourceType": "vehicle_recall",
  "primarySourceUrl": "https://www.nhtsa.gov/recalls",
  "primaryPublishedAt": "2026-10-15T08:00:00+09:00",
  "primaryTextComparedAgainstArticle": true,
  "publicTraceOverlap": "partial"
}
```

위 예시는 **형식 설명용 가상 입력**이며 실제 Y/P/N 판정 사례가 아닙니다. Y는 `publicTraceOverlap: exact`, P는 `partial`이 필요합니다. N에는 공개 원자료 URL 대신 `multiplePublicSourcesChecked:true`, `reporterEvidenceReviewed:true`, `publicTraceOverlap:"none"`을 쓰고 조사 메모를 남깁니다.

유효하지 않은 검토 행은 역추적 결과에서 U로 유지됩니다. 같은 기사에 여러 라벨이 입력되면 파이프라인은 오류로 중단합니다. 라벨 입력자는 실제 자료를 판독해야 하며 공개 URL이 있다고 해서 자동으로 그 내용의 사실성을 보증하지 않습니다.

## 지표 및 원천 우선순위
- 현재 표본수, **Y(완전 공개 원문) / P(공개 전조) / N(비공개 취재 중심) / U(미검증)** 및 취재유형별 내역을 기록합니다.
- 최소 20건 이상의 *실제 검증*이 된 유형에서만 임시 `(Y+P)/사람 검증 표본`과 `Y/검증 표본` 분자/분모를 내보냅니다. 임의 점수·단독 적중률, 전국 기사 모집단 도달률을 주장하지 않습니다.
- 표본 선정 편향이 있으므로 사용자는 최소 300~400편을 연도·산업·매체별로 나눠 검토하고 후보가 공개자료로 재현 가능한 원천 유형 순위를 결정합니다.
- 원천 유형 예: 회사 공지·약관, 정부 인증·인허가, 행정처분, 공공 조달, 법원 공고, 해외 법인 등기, NHTSA 리콜, 특허, DART.
- `confirmedScoops`, `approvedArticles`는 자동 0 유지. 기자 검증 라벨은 과거 기사 연구이지 지금 출고할 단독을 의미하지 않습니다.
