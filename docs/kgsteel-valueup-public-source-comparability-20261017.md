### 아직 증명되지 않은 것
- 2026년 계획 **공식 첨부 PDF**의 해당 목표 수치·본문 조항을 이 레이더에서 아직 직접 읽지 않았다. 금액/목표를 직접 검증한 공식 기재라고 표시하지 않는다.
- 2025년 중장기 30%와 2026년 5개년 50%의 **대상기간, 계산 분모(어떤 순익), 현금배당/자사주 매입·소각 포함 여부**가 동일하다는 증거가 없다.
- 2026 목표 달성, 실제 배당 증가, 외부 시장 영향 및 독점 보도 여부 확인 없음.
- 따라서 기사에서 '주주환원율 목표 30→50%, 20%p 상향 확정'이라는 비교를 하지 않는다.
- '2026년 50% 목표' 그 자체는 이미 국내 언론 기사에 나왔으며 단독 아니다.

## 기술 구현과 검증 장치
- data/valueup_first_party_prior_evidence.json은 원자료 종류(2025년 회사 자체 발표)와 2차 자료(2026년 선행 언론 기사)를 분리해 보존한다.
- scripts/valueup_first_party_crosscheck.py는 공식 DART 목록의 **동일 발행사·법인코드·접수번호·날짜·정정 아님·정확한 원문 URL**이 모두 맞아야 기존 공식 회사 발표와 연결한다.
- 단순 회사명/섹터 유사, 타회사 기업가치제고계획, 정정 공시, 잘못된 날짜, 공시 원문이 아닌 포털 주소, 임의 확정 숫자에선 검증이 성립하지 않는다.
- 기존 reporter queue 카드에 과거 계획과 2026년 이미 보도된 목표의 출처를 병기할 뿐, 기사 후보 건수를 새로 늘리지 않는다. 날짜는 2026년 공시 접수일이고 회사 공식 2025년 발표는 '오늘 뉴스'로 재사용하지 않는다.
- 외부 API 새 호출 없이 이미 정상 수집되는 OpenDART 공식 목록을 활용한다.
- 원문 첨부 PDF 읽기/배당 기준 검증 후에만 두 해 주주환원율의 숫자상 비교 가능 여부를 별도로 판단한다.
