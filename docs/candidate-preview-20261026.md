# 등록 원문·보도 재조회 업데이트

기준 main: 23a0d94a. 대상은 기존 수동 등록 조사서 5건이며, 전체 NHTSA·DART·자동 발견 후보를 재검증하는 기능은 아니다.

## 수정

- 기존 해시 비교는 한 번의 조회 실패 뒤 비교 기준을 잃고, 같은 문서 ID의 URL 변경을 구분하지 않았다. URL·해시·시각을 검증한 직전 성공 스냅샷만 비교하고 여러 번의 장애에도 기준 해시를 보존한다. 과거 사실을 현재 확인 사실로 복사하지 않는다.
- 페이지 텍스트의 변경/동일/첫 기준/조회 실패를 구분한다. 변경은 메뉴·꼬리말 차이일 수도 있으므로 실제 사업 변화나 새 발표로 단정하지 않는다. 문서 전문은 새로 저장하지 않는다.
- 기존 평일 원문 재조회 실행에 등록 검색어별 Google News RSS 조회를 추가한다. 최근 365일 제목 검색의 일부 색인일 뿐 국내 보도 전수·기사 전문·동일 사건 검증이 아니다. 실패·정상 응답·유효 제목·날짜 제외·응답 제한을 분리한다.
- 후보 화면에 재조회 실행 ID·실행 링크·비교 기준일·원문 오류·관련 기사 제목과 RSS 발행시각을 표시한다. 근거가 사라져 후보에서 제외돼도 조회 실패 기록은 표시한다.
- 화면 버튼은 GitHub 실행 페이지로 연결한다. 브라우저에서 비밀키로 Actions를 실행하거나 링크 클릭만으로 실시간 재검증했다고 표시하지 않는다.

## 검증

- 신규 Python 회귀 5개, 기존 원문/게시 검증 10개, 공식 수집기 95개 통과.
- 기존 후보·취재 기록 Node 회귀 스크립트 2개 통과. 실패한 원문이 후보로 생성되지 않으면서 재조회 기록에 남는지 추가 검증.
- 운영 파일을 쓰지 않은 실제 조회: 원문 7개 중 5개 일치, SEC 2개 HTTP 오류. 성공 5개 중 텍스트 동일 4개, 변경 감지 1개(미국 대법원 페이지, 변경 내용 미확정).
- RSS 5개 응답 성공. IPGATE·현대차 관련 유효 제목 1건 관측, 나머지 4개 검색은 유효 제목 미확보. 이 결과로 미보도/단독을 주장하지 않는다.

## 남은 범위

- 정확한 본문 구역·문장 단위 변경 비교, 검색 채널 확대와 기사 전문 대조, 사건 단위 일치 판정.
- 등록 후보 밖의 NHTSA·DART 등 재검증 범위 확대.
- SEC 접근 장애 해결과 화면 배포/전체 뉴스 수집의 분리.
