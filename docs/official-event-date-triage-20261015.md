# 특허 외 공식자료: 문서 발행일 기반 조사 대기열

2026-10-15 현재 KIPRISPlus 최신 조회는 공식 오류코드 22로 중단됐습니다. 이 기능은 KIPRIS 키와 독립적으로 저장된 DART·미국 연방관보·EU TED·NHTSA·공시 비교 자료를 검증합니다.

## 기존 문제
- 기존 통합 화면은 과거 8월 DART 공시 수치 비교, 1월 NHTSA 리콜, 갱신된 통계 집계를 하나의 목록에 노출했습니다.
- 오늘 수집한 원자료가 오늘 공고된 사건이라는 의미는 아닙니다.
- 정정공시의 원계약 확인 전 최신 계약이라고 쓰거나 해외 검색어 일치만으로 낙찰·수주를 단정하면 안 됩니다.

## 신규 구조
- scripts/official_event_triage.py: 기존 공식 원천 5개를 다시 가공하고 신규 API를 호출하지 않습니다.
- official-today.html: 공식 문서일 기준 최근 한국 날짜 3일의 DART 비정정 공개공시, 실제 법인명이 직접 확인된 연방고시·EU TED만 취재 검토 카드로 표시합니다.
- DART는 14자리 접수번호와 공식 링크·공개일을 교차검증합니다. 원공시 연결이 미확인된 정정공시는 제외합니다.
- 해외 고시는 nameVerified=true 및 companiesMentioned에 명시된 기업만 취재 관련성이 관측됐다고 표시합니다. 낙찰·계약·사업화 단정 금지.
- DART 투자일정 2개 공시 직접 비교와 동일기간 수치 비교는 실제 공시 접수일이 오래됐으면 과거 참고자료로 표시합니다. 준공 지연·실제 물량 증가를 추측하지 않습니다.
- 이미 공개된 NHTSA 리콜은 최근 API 재조회 여부와 관계없이 참고자료로만 노출합니다.
- 전국 HS4 통계와 시도별 관세청 집계는 특정 업체의 계약/수출 실적으로 승격하지 않습니다.
- 원천별 최신 수집 시각·오류 수·미연결/오래됨 상태와 첫 관측 시점을 분리합니다. 부분 자료=0건 아님.

## 발제 검증
① 공식 문서 자체가 최근 공개됐는가 ② 정확한 법인명·접수번호가 있는가 ③ 계약 조건/기업 사업 영향 원문 수치가 있는가 ④ 기존 전문지·기업 발표/동일 사건 기보도 여부 ⑤ 당사자 확인. 부장 보고 전 근거의 범위와 주장할 수 있는 결론을 구분합니다.

처음 실행한 데이터는 최초 관측 기준선일 뿐, 신규·미보도 단독 증명이 아닙니다.
