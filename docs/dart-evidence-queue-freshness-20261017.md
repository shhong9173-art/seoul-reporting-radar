# 공식 DART 수집 → 취재 대기열 갱신 순서 회귀 수정 (2026-10-17)

## 실제 운영 재현
PR #171 병합 후 2026-10-17 20:49 KST Industry Beat DART Official Disclosure Monitor는 완료 성공, KG스틸 20261016800823(기업가치제고계획), 20261015800723(주식소각결정), 20261015000414(자기주식 처분)을 official DART 목록에 수집했다.

그러나 Evidence-first Reporter Queue가 DART 공식 원천 갱신과 병렬 시작되어 20:49:26 KST 구버전 대기열에 최근 중요 공시 제목 확인 건수 0이 남았다. 실제 KG스틸 신규 공식 자료 0건이 아니라 **원천보다 앞서 재생성한 순서 문제**.

## 수정
- 공식 DART 수집에서 validated DART data 4개를 단일 writer로 푸시한 직후, **원격 main의 최신 공식 소스**를 다시 받는다.
- 같은 CI 통과 코드로 reporting_evidence_queue.py를 다시 실행하여 갱신된 DART를 근거로 원문 대기열 재생성하고, 기존 검증된 queue writer로 게시한다. API 요청 추가 없음.
- 별도로 돌아가는 이전 증거 대기열 작업이 뒤늦게 푸시하더라도 새 원천 스캔의 sourceHealth.dartBeat.generatedAt보다 오래된 입력이면 덮어쓰기를 거부한다.
- 수집 실패나 원천 미확인은 스캔 0건이 아니다. source 시간은 자료 수집 시점일 뿐 실제 공시 발행일이나 기보도 여부의 증거가 아니다.
- 실제 bare Git remote에서 신규 원천 → 이전 원천 덮어쓰기 거부 → 나중 신규 원천 정상 게시 → 원천 없음 오류 거부의 4단계를 검사한다.

기사화 기준: 공식 DART 공시 목록의 제목만 수집된 기업가치제고·주식소각은 '기보도 여부·본문 숫자·기업 효과 미확인'으로만 분류한다.
