# 기업가치제고계획 DART 공식 원본문서 직접 조회 (2026-10-17)

## 해결하려는 실제 병목
2026-10-17 20:54 KST의 DART 산업부 모니터는 KG스틸 공식 가치제고계획 20261016800823과 주식소각결정 20261015800723 접수 제목을 수집했지만 원문 내용은 `not_inspected_bounded_detail_budget`로 남았다. 기존 `scripts/dart_beat_monitor.py`는 계약·생산·투자 내용에만 DART document.xml ZIP 읽기를 허용했다. 가치제고 공시는 공식 1차 자료 내용을 전혀 읽지 못하고 언론 공시 소개만 붙었다.

## 이번 수정
- DART 공식 공시목록에서 회사·고유번호·접수번호·접수일·링크 및 정정 여부가 검증된 **현재 가치제고계획**만 원본문서 API로 직접 요청한다. 동명이거나 2025년 기공시, 정정 자료를 임의로 같은 신규 접수로 취급하지 않는다.
- 기존 OpenDART `https://opendart.fss.or.kr/api/document.xml` ZIP 수집기를 재사용한다. 원문 XML/HTML을 각각 최대 2MB, 최대 12개로 제한하고 외부 API 키를 공개 파일에 기록하지 않는다.
- 공식 원문 텍스트에 실제로 존재하는 `2029년 PBR 0.5배 이상` 및 `5개년 목표 주주환원율 50%` 등 **엄격한 문구**가 발견되면 글자 그대로 일부만 발췌하고 원문 텍스트의 SHA-256을 기록한다. 없는 문구는 `조회된 공식 원문에서 이 패턴 미발견`일 뿐 '그런 목표가 0건'은 아니다.
- document.xml ZIP 수집이 해당 KRX 자율공시에 지원되지 않거나 일시 실패하면 `valueup_document_unavailable`과 에러 종류만 보존하고 자동 재시도 대상으로 둔다. 정상 읽기와 원천 장애를 구분한다.
- 공식 텍스트를 읽더라도 첨부 PDF를 검토한 것, 목표가 실현된 것, 2025년 30%와 2026년 50%의 기간/분모가 일치하는 것은 전혀 입증하지 않는다.
- 기존 계약 내용의 상세 조회 우선순위와 상한(12개)을 유지한다. 가치제고 추가 상세요청은 최신 공식 DART 대상만.
- 기존 취재 대기열에 공식 원문 텍스트 근거가 있으면 별도 구획으로 표시하고, 그렇지 않으면 '원천 미연결·원문 재확인 필요'로 노출한다.
- 계약 문서 누락·특허 KIPRIS 코드22·기보도 검색 미발견은 새 단독 0건으로 판단하지 않는다.

## 운영 결과를 확인할 때의 주의
코드 병합 뒤 CI·실제 DART API 실행으로 20261016800823의 공식 XML ZIP 수신 가능 여부를 확인해야 한다. API가 8xxxxx 거래소 공시에 ZIP을 제공하지 않으면 공식 원문 본문 확보는 아직 실패인 것이므로 국내외 매체 문구를 공식 1차 확인으로 올려선 안 된다. 그런 경우 다음 개선은 DART 공식 뷰어 본문과 원문 첨부파일 다운로드 방식의 출처 정합 검증이다.
