# 공식 원자료 3개 시점의 투자 계획 기재 변화 탐지

기존 scoop.json에서 원문 수집 176건에도 후보가 없던 문제를 해결하기 위해, 키워드/공시명 중심이 아니라 두 개 공식 사업보고서의 동일 투자 항목 행을 직접 대조한다.
2025년 연간 사업보고서의 '진행중인 투자' 표와 2026년 최신 반기/분기보고서의 표에서 동일 회사·투자사업명·설비종류·사업목적·투자시작시점·백만원 단위를 검증한다.
이와 별개로 2024년 연간 공시에서 동일 사업명이 확인되면 이전 투자기간 종료 예정월과 연속된 수정 이력을 남긴다.
종료 예정월은 실제 준공, 생산시설 가동, 계약 공급일과 서로 다른 변수다. 원인과 사업 영향, 실제 최초 공개일·기존 기사 여부는 회사 직접 취재 전 확인 불가.

## 실제 원문 사례
HD현대일렉트릭: 2025 사업보고서 접수번호 20260316000940, 2026 반기보고서 접수번호 20260814003228.
- 청주 배전캠퍼스 신축 계획 종료 예정월 2026.06 → 2026.12 (+6개월). 투자액 118,473 → 116,563백만원 (-1,910백만원). 청주 공장 실제 가동 관련 보도가 이미 존재하므로 실제 가동 지연 단정 금지.
- 변압기 철심공장 계획 종료 예정월 2026.01 → 2026.11 (+10개월), 35,091 → 35,056백만원. 2024년 공시에는 2025.04 투자 종료 예정월 기재.
- 중저압차단기 자동화설비 계획 종료 예정월 2026.05 → 2026.10 (+5개월), 21,453 → 19,602백만원. 2024년 공시에는 2025.12 종료 예정월 기재.
- 미국 앨라배마 2공장 투자 확대는 이미 2026년 8월 증권사 리포트 및 기사에 등장. 동일 행/사업 세부구조가 달라서 이번 7열 비교 대상에서도 제외됨.

## 서비스
- scripts/investigation_hunt.py : 공식 원문 검증과 사업별 기재 변경 탐지, 정확한 사업명 중심 기사 검색, 회사별 /desk 한 문장 야마·반론·기사 선행 여부 체크.
- digests/investigation_hunt_latest.json : 검산 결과 및 조사 카드. 단독 확정 0건 상태를 유지.
- hunt.html : 실사업별 투자 계획 변경 사실, 2024년 공시 이력, 원문 두 개, 관련 기사 후보, 취재 질문.
- .github/workflows/investigation-hunt.yml : 평일 08:45 KST 기존 원자료 JSON을 읽어 자동 갱신.
