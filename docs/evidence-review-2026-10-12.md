# 원자료 근거 중심 취재 검토 엔진

## 구현된 첫 단계
- 공시 digest와 DART 원문 추출 데이터를 접수번호와 기업명 양쪽이 일치할 때만 결합한다.
- 정정항목·정정전·정정후는 발행인이 정정표에 기재한 내용이며, originalDocumentVerified=false인 경우 최초 원공시를 독립 대조했다는 주장은 금지한다.
- 원문 숫자 숫자값은 표시할 수 있으나 금액 변화나 실제 손익으로 해석하지 않는다.
- 같은 회사·같은 보고서명만으로 서로 다른 계약을 연결하지 않는다.
- 임원·주요주주 보유 신고, 정례 사업보고서, 자사주 처분을 그 자체로 단독 후보로 올리지 않는다.
- 네이버 API(연결 시) 또는 최근 30일 Google News RSS에서 관련 기사 후보를 조회하되, 같은 사건 여부는 검증 전이고 결과 0건도 미보도 확정이 아니다.
- 기사 검색은 기업+사건 키워드 10쿼리 상한. 실패·불완전 범위는 별도 상태로 표시한다.
- 기사 원문 및 보도 여부 직접 검증·회사 답변 전에는 단독 판정과 발제 확정을 하지 않는다.

## 파일
- scripts/review_engine.py: digests/latest.json + dart_numeric.json → digests/review_latest.json 생성.
- morning.html: 검토된 네 가지 범주를 표시하고, 최신 digest와 검토 생성 원본 시각이 다르면 이전 검토 결과를 숨긴다.
- scripts/trade_trends.py: 관세청 CSV의 동일 HS·동일 월 수출액·중량·단가(USD/kg) 비교. 계약금액·회사별 가격이라는 주장은 금지.
- 기존 scoop_scout.py, DIRECT_BEAT_COMPANIES 및 운영 데이터 분류 규칙은 이 단계에서 변경하지 않았다.

## 현재 구현하지 않은 기능
1. 원공시와 정정공시의 전체 본문을 별도로 다운로드해 동일 계약을 검증한 전후 금액 자동 산출.
2. 동일 사건에 대한 더벨·딜사이트·전문지까지 포괄한 미보도 확정.
3. 해외 공급사·생산거점·HS 코드가 실제 국내 기업의 특정 사업에 영향을 준다는 인과 검증.
4. 회사 홍보팀 실제 답변 및 발제 확정.
5. 미등록·비상장 회사의 공시 전수 수집.

2. 실제 DART 고유번호 미확인 기업 한국GM·LS엠앤엠·동성케미칼의 공시 대상 여부와 법인명 점검.

4. 관세청 API 기반 HS·국가·월별 금액/중량/단가 원표 화면과 비교 기준 자동 검증.
