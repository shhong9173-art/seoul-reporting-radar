# KG스틸 DART 출입처 누락 해소: 공식 상장 종목코드로 법인명 중복 해소 (2026-10-17)

2026-10-17 운영 DART 산업부 모니터는 48개 중 44개 법인의 코드로 조회했고, KG스틸은 OpenDART 고유번호 전체목록의 이름이 같은 법인 2개 때문에 코드가 확정되지 않아 조회 대상에서 빠졌다. KG스틸의 한국거래소 상장 종목코드는 016380으로 공개돼 있다.

참고: https://ohgong.com/dart/016380 (OpenDART 기업개황 기반 회사·종목코드), https://opendart.fss.or.kr/guide/main.do?apiGrpCd=DS001 (공식 corpCode ZIP의 회사명·고유번호·종목코드 필드).

## 구현
- OpenDART 공식 corpCode.xml의 **동일 행**에서 반드시 법인명이 KG스틸/케이지스틸(법인격 접두미사 제거)과 일치하고 stock_code가 정확히 016380인 고유번호만 표시한다.
- 동명 공식 법인이 2개 이상이어도 종목코드 016380에 해당하는 정확히 **1개 고유번호**만 확인되면 새 DART 모니터 조회법인으로 등록한다.
- 공식 등록부에 증거가 없거나, 종목코드가 둘 이상에서 발견되거나, 다른 회사명이 같은 종목코드를 사용하거나, 이미 검증한 기존 코드가 충돌할 경우 자동으로 덮어쓰지 않고 '고유번호 미확인/수동 대조' 상태를 유지한다.
- 새로 조회 가능한 KG스틸의 **기존 공개 공시**는 기존 모니터에서 '단독'이 아니라 '새로 연결된 출입처의 이전 공개 원문'이라고 분류하는 기존 규칙을 사용한다. 상장 종목코드가 모든 자회사 공시를 포함한다는 뜻은 아니다.
- 나머지 BMW코리아·아우디코리아·폭스바겐코리아 미매핑은 다른 법인으로 임의 연결하지 않는다.
- DART 공식 원문 직접 조회 데이터가 갱신된 뒤에야 공시 범위 확대 성공 여부를 확정한다.

## 테스트
공식 등록 ZIP과 동일한 XML 형식의 1000개 이상 법인 fixture로 동명 두 법인/올바른 상장코드/중복 상장코드/타법인 가짜 상장코드/기존 불일치코드 보존을 검증한다. GitHub Actions가 공식 등록부를 실제 조회하도록 배포 트리거에 등록했다.
