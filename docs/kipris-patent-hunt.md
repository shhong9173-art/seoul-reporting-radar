# KIPRISPlus 공식 특허 공개공보 단독 취재 탐색기

## 선배 /hunt 원칙 적용
- 특허는 기업의 **기술 구상·연구개발 방향**에 관한 취재 단서지, 출시/양산/인허가/사업 확정/특허 등록/독점 특허 증거가 아님.
- 회사 출입처 **정확한 특허 출원인명**과 최근 공개일·공개번호·발명명칭·초록·IPC를 KIPRISPlus API에서 수집. 날짜는 출원일과 공개일을 분리해 표시.
- 보도 없는 기술이라고 주장하려면 동일 기술 기존 특허, 우선권, 패밀리(해외 공개 포함), 기존 회사 IR, 전문매체, 기보도 기사, 회사 직접 답변을 대조해야 함.
- 공개번호를 Google News RSS에서 검색하되 결과가 0건이라도 **미보도 단독**이 아님. 검색이 정상인데 출원인이 전혀 일치하지 않으면 회사별 **오류/0건**을 구분.
- 회사 관련성과 분야가 확실할 때만 후보로 분류. 자율주행/SDV, 전기차/배터리, 전력망/HVDC, 저탄소제철, 수소, 공장 자동화 중심. 카메라/조향 등 분야가 미리 정한 패턴에 없으면 자동 누락될 수 있음.

## 공식 API
- [KIPRISPlus 특허·실용 공개·등록공보](https://plus.kipris.or.kr/eng/data/service/DBII_000000000000001/view.do?menuNo=300100&subTab=SC001)
- [고급검색(getAdvancedSearch) 공식 개발 표](https://plus.kipris.or.kr/portal/popup/DBII_000000000000001/SC002/ADI_0000000000002944/apiDescriptionSearch.do)
- Operation: `/kipo-api/kipi/patUtiModInfoSearchSevice/getAdvancedSearch` (공식 문서의 `Sevice` 철자 준수).
- 실제 입력: `applicant=<검증 예정인 출원인명>`, `openDate=YYYYMMDD~YYYYMMDD`, `patent=true`, `utility=false`, `sortSpec=OPD`, `descSort=true`, `ServiceKey`.
- 응답 공식 필드: `applicationNumber`, `applicationDate`, `openNumber`, `openDate`, `registerStatus`, `inventionTitle`, `astrtCont`, `applicantName`, `ipcNumber`. 상세 청구항은 별도 원문 조회 필요.
- 서비스 가입 후 **해당 특허/실용 공보 API 승인 및 ServiceKey 발급**이 필요. 기존 **관세청 `CUSTOMS_API_KEY`와 다른 인증**이다. GitHub 저장소 Settings → Secrets and variables → Actions에 `KIPRIS_SERVICE_KEY`로 등록. 공개 GitHub 파일이나 채팅에 실제 값을 게시하지 않는다.
- 최신 일 35일을 보지만 신규 수집의 **첫 실행은 기준선**이다. 다음 실행부터 `seen`에 없던 공개번호를 신규 관측으로 분류한다. 새 관측=처음 출원/처음 공개라는 뜻이 아님.
- 지적재산 권리 상태(공개, 등록, 소멸 등)는 결과에 그대로 저장하되 공개특허가 무조건 등록됐다고 주장하지 않는다.
- 월~금 오전 9시 15분(KST) KIPRIS 공식 자료 체크, 인증키 없으면 **인증키 미연결**을 화면에 명시. 인증이 있는데 모두 실패하면 현재 자료를 덮어쓰지 않는다.

## 범위
- 자동차/철강/비철/전력기기/에너지 출입처 24개 정확 법인명. 포스코/포스코홀딩스, LS/LS MnM, 현대차/현대모비스 등 계열사와 브랜드는 **자동으로 동일 출원인이라 여기지 않음**.
- 출원인 1개당 최대 2페이지×100건. 총 건수가 넘어가면 `truncated`로 표시하고 '전체 특허'라고 주장하지 않는다.
- 검색 결과에 공식 출원인명이 한글 공백/표기와 다르면 현재 알고 있는 법인 정식 이름과 정확히 대조 후 수집 (법인 표기 변경·흡수합병 시 업데이트 필요).
- 관련 기술 키워드가 제목 또는 초록에 확인된 자료만 상단 우선순위를 부여한다. 독점/단독 확률 점수가 아니다.
- 출원인 확인, 공개번호, 공개일, 공개상태, 청구항, 상품화 여부, 기존 관련기사 검증 단계별 확인.

## 실제 상태 및 한계
- 이 구현에는 사용자의 KIPRIS ServiceKey가 제공되지 않았다. **운영 환경에 별도 키 등록이 없다면 실제 특허 자료는 수집되지 않으며 결과 화면은 미연결 상태**로 남는다.
- 2026년 1월 공개된 현대차·기아의 자율주행 제어 공개특허와 HD현대일렉트릭 DC/DC 변환기 국제공개 특허 등은 검색 사례일 뿐 신규 특종이 아님.
- 대한민국 특허 외 해외 패밀리 WIPO/US/EPO 조회, 실제 청구항 변화 분석 및 KIPRIS 과거 5년 동일 출원인·IPC 대비 희귀성 측정은 다음 개선에 해당.
- 선배가 특허로 3건 단독을 냈다는 사실은 사용자가 전한 사례이며, 해당 원자료·보도·구체적인 취재 과정은 제공되지 않아 그대로 복제했다고 주장할 수 없다.
