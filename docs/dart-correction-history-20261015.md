# 정정공시 이전 이력과 언론 색인: 동일 계약 확인 전 단계

2026-10-15 저장된 OpenDART 정정공시 네 건 중 **두산에너빌리티**는 과거 날짜의 후보 접수번호가 없고, **영풍·효성중공업·세아제강**은 각 1건의 **같은 발행회사/공시유형/정정문 최초 제출 참고일에 포착된 접수번호**만 있습니다. 이 후보를 '기존 계약'이나 '동일 사건'으로 분류하는 것은 금지합니다.

## 자동화한 새 확인 과정

- \`scripts/dart_correction_history.py\`는 이미 정식 DART 목록에서 수집해 근거가 있는 후보 번호만 입력으로 받습니다. 접수번호(14자리), 해당 접수일, DART 공식 URL, 현재 공시보다 과거 날짜, 같은 공시 유형 및 해당 기업 날짜별 조회에서 왔다는 상태를 재검증합니다.
- 검증을 통과한 **과거 후보 공시의 OpenDART \`document.xml\`을 최대 8회/실행, 각 정정공시당 최대 2회** 조회합니다. ZIP의 공개 원문을 직접 검사하며 API 응답 오류·키 부재·미검사를 구분합니다.
- 과거 접수가 정정공시면 그 *과거 정정문 자체*의 '정정 후' 기재값을 검사하고, 일반 공시면 과거 공개 원문의 정확한 표 항목을 읽습니다. 이번 정정문의 **'정정 전' 기재값**과 문자·숫자 표기가 동일한지 기록하되 **기존 계약 동일성 미확정**으로 표시합니다. 기재값 상충도 현상 분석을 위한 취재 단서에 불과합니다.
- 지난 Google News RSS 검색 결과 중 **이번 정정일보다 이전 날짜**로 색인된 기사만 별도 참고합니다. 기사 전문을 읽지 않았고 단지 색인 제목·일자를 비교한 것이므로 이 거래와 관련된 기사인지, 이번 수정 내용이 실제 선행보도됐는지 모두 미확인입니다. 색인에 기사가 없다고 미보도나 단독이라고 판단하지 않습니다.
- \`dart-correction-history.html\`은 과거 후보 DART 링크, 실제 원문 조회 성공·미실행·에러, 공시상 기재값 일치 여부, 기사 색인 후보를 **동일 계약·기보도 승인과 분리한 취재 화면**에 표시합니다. \`dart-contract-followup.html\`에서 연결됩니다.
- OpenDART 키는 GitHub Actions Secrets에서만 읽습니다. 출입처가 공개할 수 없는 내부 계획, 비공개 고객 계약, 향후 납품량 추측을 취재 질문으로 생성하지 않습니다.

## 이 기능으로 *증명하지 못한 것*

- 이전 정정공시 후보가 현재 계약과 법적으로 동일한 계약인지는 정확한 원계약번호·공시 원문 연결·관련 공시 이력 검증 전 불명입니다.
- 과거 공시의 금액이 현재 '정정 전' 금액과 문자상 동일하더라도 같은 계약이라는 의미는 아닙니다.
- 뉴스 RSS 색인된 기사의 제목·일시가 이전이더라도 이번 정정 금액·납품 변경 사실이 기보도됐다는 증명은 아닙니다.
- 기존/정정 공시 자체는 이미 공개됐습니다. 9~10월 초 정정을 10월 15일 신규 단독으로 분류하면 안 됩니다.
- 확인 가능한 출입처 기자 질의는 공시의 실제 계약조건/정정 이유 중 대외 공개 가능한 사실에 집중합니다. 내부 전략·미공개 공급망·미확정 향후 의사결정 질의는 배제합니다.

## 완전성·검증

\`tests/test_dart_correction_history.py\`는 과거 *정정공시*와 *최초 공시* 두 원문 방식, 완전 일치·불일치, 타사/다른 날짜·URL·공시 유형 후보 차단, 중복 제거, 기사 RSS 미조회/부분실패/기사 날짜, 외부 조회 8회 상한, 실제 커밋된 공식 스냅샷 오프라인 분석을 검증합니다.

2026-10-15 데이터 기준 과거 같은 회사/공시 유형/최초 제출일 후보 **3건**의 공식 문서 실조회가 병합 후 새 Actions에서 성공했는지 \`digests/dart_correction_history_latest.json\`의 \`historicalDocumentsRetrieved\`와 개별 원문 상태를 확인해야 합니다. **테스트 통과와 실제 원문 재조회 성공은 별개의 사실**입니다.
