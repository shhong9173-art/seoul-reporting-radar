# 임원 기사 본문 근거 확인

## 원인과 수정

기존 `kr_exec_check.py`는 네이버 검색 제목·요약에서 이름/기관/부정적 단어를 찾으면 과거 논란 기사로 표시하고 강한 단어면 A를 부여했다. 본문 수집은 없었다. 공시의 현재 등재와 기보도 내용을 결합해도 단독 또는 비위 사실을 확정할 수 없다.

- `executive_article_evidence.py`: 허용한 언론 도메인의 공개 HTML만 제한적으로 읽는다. 자동 리다이렉트 금지, 목적지 재검사, 최대 3회 요청, 연결 4초/읽기 8초, 1.5MB 제한, 실행당 본문 30 URL. 본문 영역/NewsArticle.articleBody만 추출하며 검색 요약·문서 전체·사진 설명·메뉴는 대체 본문으로 쓰지 않는다.
- 본문 한 문장에서 인물 이름과 공시에서 가져온 소속/경력 기관, 직함, 사건 단어가 연결되는지를 보수적으로 점검한다. 계열사 접두어·다른 문단·다른 사람의 사건·발언 인용·무죄 등 처분 문맥은 자동 표시를 보류한다.
- 본문 연결은 B 확인 단서까지만 허용한다. 동일 인물·혐의 사실·미보도·단독의 입증이 아니다. 본문 실패와 미지원 구조, 문맥 미확인, 실행 한도는 분리 기록한다.
- URL·확인 시각·추출 방식·본문 해시/길이·최대 120자 발췌만 기자 전용 저장소에 남긴다. 전문은 저장하지 않는다. 일일 캐시는 인물/기관 문맥 키가 같을 때만 재사용하며 실행 한도 때문에 미조회한 URL을 다음 실행에서 우선 처리한다.
- 기존 기사만 있는 구버전 이벤트는 Worker에서도 알림에서 제외한다. 상세 목록에는 미확인 상태와 원문 링크를 남기고, 기존 공시 기반 임원 판정은 유지한다.

## 검증

- 임원 본문·명단·시장 추적, 보도 대조, 단독 심사 및 공식 수집기 회귀 테스트를 실행한다. Worker의 구버전 기사 알림 제외·미확인 상세 표시도 테스트한다.
- 공개 기사 실조회: [아이뉴스24](https://v1.inews24.com/view/1998581) 본문 2,116자, [뉴시스](https://nwww.newsis.com/view/NISX20261014_0003826119) 본문 1,065자 추출. 이는 파서 확인용 일반 산업 기사이며 새로운 취재 단서 발굴 결과가 아니다.
- 뉴시스는 처음 body_missing이었다. 실제 `article-cont` 구조를 확인해 지원했고 사진 설명은 제외했다. 해당 HTML 구조를 가상 인물 문장으로 회귀 테스트에 반영했다.

## 한계

지원하지 않는 도메인/본문 구조, 유료·로그인 페이지는 미확인으로 남는다. 문장 패턴은 관계를 완전히 이해하지 못하며 놓치는 기사가 있을 수 있다. 동명이인·당사자 역할·후속 판결/처분·실제 기업 영향은 원문 전체 및 회사 확인이 필요하다. 본문에 처분 문맥이 없어도 처분이 없다는 뜻이 아니다. 모든 날짜는 검색 결과의 기존 날짜를 보존하며 본문 확인 시각으로 대체하지 않는다.

운영 키를 로컬로 복사하지 않는다. 병합 후 기존 Actions 보안 설정에서 실제 조회·저장 결과를 별도로 확인한다.
