# NTIS 성과검색(특허) → KIPRIS 출원번호 → 국가과제 교차검증

## 지금까지 공식 확인된 범위

- 국가R&D 과제검색(OpenAPI): 승인된 Windows PC에서 2026-10-14 8개 검색식, 27개 결과, 26개 고유 과제번호를 수집. **검색어만으로 과제·특허의 직접적인 관계는 확정되지 않습니다.**
- [공공데이터포털 NTIS 국가R&D 성과검색(전체용)](https://www.data.go.kr/data/15077316/openapi.do)은 특허·논문·연구장비 성과 메타정보를 제공하는 **별개 서비스**입니다. 과제검색 승인만으로 성과검색도 승인되었다고 가정할 수 없습니다.
- 성과검색용 **공식 최신 기술매뉴얼은 아직 확보되지 않았습니다.** 제3자 오픈소스 구현에서는 후보 요청주소를 `/rndopen/openApi/public_result`, 검색 범위를 `collection=rpatent`, `addQuery=DBT=PAT`로 사용하나 **운영 검증 전**입니다.
- NTIS 웹사이트의 특허 성과 상세 페이지는 *출원번호* 등을 표기할 수 있으나, 개별 페이지 정보와 성과검색 API 응답 필드는 동일하다고 가정할 수 없습니다.

## 1. 등록된 PC에서 안전하게 성과검색 서비스 스키마 확인

이전에 API 정상 작동이 확인된 PC·네트워크에서 다음 두 파일을 **동일 폴더에** 저장합니다.

- `scripts/ntis_patent_outcome_probe.ps1`
- `scripts/Run_NTIS_Patent_Outcome_Check.cmd`

`Run_NTIS_Patent_Outcome_Check.cmd`를 더블클릭하고 **성과검색 이용 승인된 API 키**를 PowerShell 숨김 입력란에 입력합니다.

- 후보 API 주소 1개를 제한적으로 시험합니다. 조회어는 공개된 특허 출원번호와 ‘부분방전’으로 최대 2회입니다.
- 권한 오류·HTTP 404·XML 구조 불일치·검색 0건을 특허 성과 0건이라고 판단하지 않습니다.
- 요청은 HTTPS `www.ntis.go.kr`로만 전송합니다. 출력에는 XML 필드 **이름**만 들어갑니다. 이름·출원번호 등 성과행 데이터, 개인별 정보, 응답본문, 인증키는 저장하지 않습니다.
- 결과 `ntis_patent_outcome_schema_probe.json` 파일과 공식 **국가R&D 성과검색(전체용) 기술문서 PDF**를 이 대화에 전달합니다. 키와 전체 API 요청 URL은 전달하지 마세요.

개발자가 공식 매뉴얼의 성과검색 필드와 실제 XML 필드 경로를 대조하기 전까지, 특정 필드를 ‘출원번호’ 또는 ‘과제번호’라고 자동 지정하지 않습니다.

## 2. 서로 다른 식별자 혼동 방지

`scripts/ntis_outcome_reconcile.py`는 다음 정보를 분리합니다.

- KIPRIS **공개번호**: 예) `10-2026-0145290`
- KIPRIS **출원번호**: 예) `10-2025-0039383`
- NTIS **국가과제번호**: 예) `2410019058`
- NTIS **특허 성과 레코드 식별자**: 공식 API 필드 뜻이 검증될 때만 사용

성과검색 결과의 **동일 레코드**에 국가과제번호와 정확한 특허 번호(출원번호↔출원번호 또는 공개번호↔공개번호)가 실제로 기재되고, 해당 과제번호가 공개 과제검색에도 존재해야 *번호 일치 검토 후보*가 됩니다.

**출원번호와 공개번호의 숫자를 서로 비교하면 안 됩니다.** 특정 기관·기술명·검색어의 유사성도 링크 증명이 아닙니다. 성과검색의 실제 스키마 확인 전에는 프로젝트와 특허의 연결 확정은 무조건 **0건**입니다.

번호가 정확히 일치하더라도 연차별 과제 기록·법인 실체·NTIS 원문을 교차 확인해야 하고, 실제 제품 적용·양산·사업화·기보도·단독 여부는 별도 취재가 필요합니다.

## 3. 오프라인 검증 및 다음 작업

```bash
python -m unittest discover -s tests -p 'test_ntis_outcome_reconcile.py' -v
python scripts/ntis_outcome_reconcile.py
```

출력은 `digests/ntis_patent_outcome_links_latest.json`입니다. 이는 현재 **성과 API가 미연결이라는 상태 진단**일 뿐, 공식 과제·특허 연결이 존재하지 않는다는 의미가 아닙니다.

매뉴얼과 XML 스키마가 확인되면 다음 단계로 API 파서 및 검증된 식별자 추출 로직을 작성합니다. 승인된 PC에서만 실제 수집을 수행하고, 비밀키가 없는 검증 JSON을 엄격한 출처·스키마 검사 후 취재 레이더에 반영합니다.
