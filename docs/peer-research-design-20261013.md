# 비교 데이터 발굴 엔진 · 실제 원자료와 검증 기준

## 목표와 원자료
- 선배의 `/hunt` 절차에서 중요한 것은 단순한 최신 공시 감시가 아니라 같은 지표의 시점·기업 간 비교다.
- [OpenDART 공식 API 가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS003&apiId=2019020)의 `fnlttSinglAcntAll.json`을 사용한다.
- `dart_corp_codes.json`의 직접 출입처 법인 코드만 사용하며 신규 기업을 임의 추가하지 않는다.
- 연간: 직전 사업연도 사업보고서의 당기·전기·전전기 수치(최대 3년). 반기: 당해 연도 반기 누적과 전년 동기 누적.
- 결산·반기, CFS/OFS, KRW/USD, IS/CF, 표준 계정ID를 혼용하지 않는다. 불명확한 값은 미확인으로 남긴다.
- 기준 기간: 2026년 10월 운영 시 연간 2025년(2023~2025), 반기 2026년(2025년 동일 반기와 비교).
- 표준 계정ID의 매출액과 영업이익만 초기에 채택해 재현 가능한 수치부터 검산한다.

## 평가 규칙
- 자동차 완성차 현대차/기아, 자동차 부품 현대모비스/현대위아/HL만도, 전력기기 HD현대일렉트릭/LS일렉트릭/효성중공업, 철강 현대제철/동국제강/세아제강, 비철 고려아연/영풍.
- 같은 시점에 **비교 가능한 회사가 3곳 이상**이고, 특정 회사 매출 증가율이 나머지 회사 중앙값보다 15%포인트 이상 차이 나면서 절대 증감률 10% 이상일 때 '취재 단서'로 표시한다.
- 회사별 사업구조/제품군 차이 때문에 중앙값은 ‘산업 전체 평균’이 아니며, 개별 회사 간 내부거래 중복으로 매출액을 합산해 산업 규모를 계산하지 않는다.
- 2개 회사 그룹은 표만 제공한다. 2개 회사만으로 집단 이상치 판정을 하지 않는다.
- 이상치 자체는 이미 보도됐을 수 있다. `선행 보도 미검증`, `단독 미확정`을 명시한다.
- 이번 단계는 **사업보고서 중심의 고정 주기 데이터 탐색**이다. 당일 미보도 속보 탐색을 대체하지 못한다.

## 구현
- `scripts/peer_financial.py` OpenDART CFS 수집, 출처 접수번호 보존, 2가지 기간·기업 그룹 비교, 증감률 및 격차 계산.
- `data-lab.html` 출입처 그룹·기간별 표와 취재 질문을 제공. 최초 생성 전에는 파일 미게시를 정확히 표시한다.
- `.github/workflows/peer-data-research.yml` 매주 월요일 오전 7시 20분 KST 실행(일정 지연 가능), 추가로 Actions 수동 실행 가능.
- 기존 radar writer와 같은 concurrency 그룹을 사용. 공식 API 장애나 수치 추출 회사 3개 미만이면 기존 결과 덮어쓰기 차단.
- `tests/test_peer_financial.py` 및 `tests/test_data_lab.cjs`는 완전 오프라인 회귀 테스트.

## 후속 개발 (아직 구현되지 않음)
1. OpenDART 현금흐름·수주 잔고·생산능력·R&D·공시 주석 수치 추출. 회사별 계정 정의와 단위가 다른 자료 자동 합산 금지.
2. 관세청 API 연결 시 HS/국가/기간별 수출액·중량·단가 통계의 3~5년 추이 이상치 탐색. 지금은 수동 CSV 검산 도구만 사용 가능.
3. 당일 신규 발표·사업보고서 제출 시각 기반의 증분 수집과 과거 전체 이력 검증(‘최초’, ‘최대’).
4. 네이버·구글·더벨·딜사이트·전문지의 동일 사건 이력 확인. 검색 결과 0건으로 미보도 확정하지 않는다.
5. 실제 취재 질문·기업 직접 답변 및 데스킹 통과/탈락 피드백으로 신호의 유효성 평가.

## 검증과 기사 윤리
- 연결 재무 매출액은 자동차 생산대수, 발전기 수주잔고, 수출액이 아니다.
- 3년 자료만으로 역사적 최고/최초를 판정하지 않는다.
- 공식 IR 원자료와 DART 데이터의 상충 원인은 인수합병·회계변경·재작성 등을 기자가 확인한다.
- 기업 의견·관계자 멘트·공급망 인과를 생성하지 않는다.
- 사후 실제 PR·실제 Actions API 실행·웹 화면 게시 성공 여부를 구분해 보고한다.
