## 변경

`scoop_scout.py`의 직접 출입처 식별에 `strict_company_hits`를 사용한다. 일반 뉴스용 target_hits는 유지한다. 문자 경계와 한국어 조사를 확인하고 같은 위치에서 겹치는 이름 중 긴 기업명을 우선한다. 별도로 명시된 모회사는 유지한다.

BMW·아우디·폭스바겐의 글로벌 이름을 한국 법인으로 무조건 치환하지 않는다. 국내 법인 이름 또는 실제 국내 공식 호스트가 확인된 경우만 해당 법인으로 연결한다. querySite 검색 조건이나 URL 경로에 기업 도메인 문자열이 있는 것만으로 출입처를 지정하지 않는다. 모회사 사이트에 게시됐다는 이유로 본문 제목의 별도 계열사 주체를 바꾸지도 않는다.

기존 테스트의 `BMW` → `BMW코리아`, 세아씨엠 직접 출입처 기대값도 사용자 기준에 맞게 수정했다. 명시적인 BMW코리아와 동성케미칼을 허용하는 검사로 바꿨다. 단독 점수·일반 뉴스 수집·운영 JSON은 수정하지 않았다.

## 남은 한계

전체 후보 생성·원문 실접속·기존 기사 검색·Actions·배포 검증은 수행하지 않았다. 명칭 경계가 엄격해지면서 붙여 쓴 제목이나 미등록 외국어 별칭은 누락될 수 있다. 알려지지 않은 동명 기업·그룹 관계는 법인 코드와 근거가 있는 관계 목록으로 추가 검증해야 한다. 실제 공식 호스트만으로 보완하는 방식도 게시 주체와 사건 주체가 다른 경우를 완전히 해결하지는 못한다.

후속 우선순위는 오래된 후보 재노출 방지, 원공시와 정정 공시의 사실별 비교, 동일 사건의 기존 기사 비교다. 출입처 식별 통과 자체는 단독 후보 판정이 아니다.
