# 특허 외 단독 단서 — 6개 공식 수집 영역 확장 (2026-10-13)

## 우선 구분
- **공식 원문에서 확인된 정보**와 **원문이 아직 공개되지 않거나 API 승인 전인 정보**를 나눈다.
- **단독 확인 0건**은 단독으로 입증된 사례가 아직 없다는 뜻이지 실제 소재가 존재하지 않는다는 뜻이 아니다.
- **공시 숫자 변경 ≠ 생산·수주·투자 지연이 현실화했다는 증거**. 기보도 전문, 분모·보고범위, 기업 답변, 사업 실제 영향 검증 후 발제.
- 사용자 출입처 법인이 직접 언급된 자료와 같은 그룹/수입브랜드 미국 판매자료를 혼동하지 않는다.

## 1. /hunt DART 원문 변화
- `scripts/business_content.py`의 직접 출입처 범위를 7개사에서 **21개사**로 확장. `dart_corp_codes.json`에 확인된 DART 법인코드만 사용한다.
- `scripts/recent_business_scout.py`도 같은 목록을 사용해 2026년 최신 분기/반기 대 2025년 **동일 회계기간** 원문을 대조한다.
- `scripts/recent_metric_hunt.py`는 정기보고서의 일부 생산능력·실적·수주잔고·부문매출 표에 대해 동일법인, 동일 보고기간, 같은 표시단위, 정확히 같은 고유 행, 공식 접수번호를 충족할 때만 **공시상 첫 숫자** 차이를 기록한다. 단위가 없거나 행명·연도·접수번호가 맞지 않으면 제외한다. 매출 보고범위/조업일수 변경이나 단가 인상으로 단정하지 않는다.
- `digests/recent_metric_changes_latest.json`과 `hunt.html`에 이전·최신 원문 두 URL과 공시상 숫자를 표시한다.
- 동시 비교가 안 되는 회사도 진단에는 남으며, 0건이나 단독 없음으로 간주하지 않는다.

## 2. US Federal Register / EU TED
- `scripts/overseas_official.py` 검색어를 8개에서 16개로 확대. 현대모비스·현대제철·포스코·LS일렉트릭·대한전선·고려아연 등 포함.
- 미국 주·카운티 건축 허가, EPA 시설별 허가/환경규제는 **이번 버전에서 자동 수집하지 않음**. 미국 EPA ECHO 공식 웹서비스 접근 경로를 통합 화면에 표시한다. 해당 사업의 건축/환경 인허가 사실을 확인했다고 주장하지 않는다.

## 3. NHTSA ODI 자동차 안전 조사
- `scripts/nhtsa_investigations.py`: 공식 FLAT_INV.zip 탭 구분 원자료 및 11열 명세(INV.txt)에 따라 조사번호·제조사·차종·조사 개시일·부품·제목/요지를 추출.
- 최근 100일 개시 조사 중 직접 자동차 출입처/수입차 관련 제조사를 제한적으로 표시. 과거 최초 관측 시점과 레이더 신규 관측을 구분한다. 처음 관측됐다고 신규 공개나 미보도·단독이 아니다.
- 원문 설명: https://www.nhtsa.gov/nhtsa-datasets-and-apis
- NHTSA 공식 조사 **개시** ≠ 결함 확정, 국내 대상차량 동일 ≠ 국내 리콜. 리콜 및 소비자 신고/제조사 기술문서 전수 대조는 후속 과제.

## 4. 과기부 연구공모 — 선정과제 아님
- `scripts/research_procurement.py` MSIT 사업공고 API 공식 `businessAnnouncMentList`에서 최근 공모 중 출입처 산업 관련 기술주제를 선별한다.
- GitHub Secret `MSIT_API_KEY`에 **해당 별도 API 승인 키**가 있을 때만 요청한다. 승인되지 않은 경우 기존 자료 보존.
- **NTIS 과제 선정·집행·특허-정부 과제 동일성**은 별도 서비스/스키마 승인·확인이 필요하며 **아직 자동 연동되지 않았다**.
- API 안내: https://www.data.go.kr/data/15074634/openapi.do

## 5. HS6 수출통계
- `scripts/customs_hs6.py`는 HS 850421·850422·850423·850434(변압기), 854460(전기도체), 870380(전기승용차) 관련 공식 관세청 월별 자료를 기존 HS4와 분리해 비교. 10단위 한국 분류·분리 합산 여부 원문 확인 필요.
- 결과 `digests/customs_hs6_latest.json`. GitHub Secret `CUSTOMS_API_KEY`가 있더라도 **실제 API 응답의 비교 월과 숫자가 완전할 때만** 게시. 품목 믹스가 바뀌면 USD/kg 단가는 달라질 수 있다. 기업 수출액 아님.

## 6. 나라장터 — 낙찰/계약이 아닌 공사 입찰공고
- `scripts/research_procurement.py`가 공식 `BidPublicInfoService/getBidPblancListInfoCnstwk`로 지난 7일 일부 건설공사 입찰공고 1페이지 내 관련 기술어휘를 대조한다.
- 별도 Secret `G2B_API_KEY` 필요. 결과가 1페이지를 초과하면 잘렸다고 표시하고 전체 모집단으로 주장하지 않는다.
- 조회된 것은 입찰 **공고**이지 **수주/낙찰/계약체결/변경**이 아니다. 공식 계약정보 조회와 계약과정통합공개 API는 후속 연계 대상으로 남겼다.
- https://www.data.go.kr/data/15129394/openapi.do

## 실행 및 인터페이스
- `scoop-sources.html`에 6개 출처의 확인된 원문 링크와 실제 최신시각·미생성 경고·일부 데이터만 확인된 사실을 표시. 종합 `index.html`에서 직접 이동.
- `.github/workflows/cross-source-scoop.yml`: 별도 NHTSA (키 불필요), 과기부/조달 (각 별도 서비스키), HS6 (기존 관세청키) 3개 독립 작업과 화면 단위테스트.
- `.github/workflows/investigation-hunt.yml`: 원문 투자기간 변경 탐지와 더불어 최신 분기·반기 표 수치 변동 검증, 단독 인증 없음.
- 미국 NHTSA·MSIT·G2B·관세청 서비스의 실제 키/권한/네트워크 오류는 해당 공급자만 실패 처리. 다른 수집 결과는 이전 정상 버전을 보존.
