# 공보 청구항 원문 대조 기반 단독 취재 연구

## 원칙

* 본 분석은 KIPRISPlus **특허·실용 공개·등록공보** `getBibliographyDetailInfoSearch` 서지상세의 `claimInfoArray`를 원문으로 확인한다. 출원번호 `applicationNumber`로 조회하며 실제 반환값과 반드시 재대조한다. 공개번호 `openNumber`와 출원번호는 구분한다.
* **공개 공보 제1항과 현재 유효 등록특허의 최종 청구범위는 다를 수 있다**. 심사 도중 보정, 거절결정·등록 후 정정·무효 등에 따라 달라진다. 청구항 문구의 차이는 신규성·진보성/특허침해·실제 제품화의 입증이 아니다.
* 기존 제목 검색에서 **동일 출원인이 명시된 종전 공개특허**에 공식 `applicationNumber`가 있을 때에만 과거 제1항을 직접 가져와 대조한다. 출원번호·상세 API·제1항 어느 하나라도 확보되지 않으면 구체적 기술 차이를 만들어내지 않는다.
* XML 응답의 자료 범위/DTD/오류 코드/출원번호를 검증한다. 공개 GitHub에는 제1항 전문 대신 짧은 구절과 SHA-256·길이·텍스트 유사도만 남긴다.
* 같은 제목의 과거 특허 전수 조사나 패밀리 검증·독립 청구항 구성 요소 차이의 법적 해석은 이번 단계만으로 완료되지 않는다. 기존 **청구항 변동 이력 API**는 별도 상품이고, 등록결정서·의견제출통지서 또한 별도 검토할 대상이다.

## 실제 연구 질문

* 현대차·기아의 2026년 9월 공개 `1020260138678` 「자율주행 차량 제어 장치 및 방법」와 2023년 같은 제목의 문헌 `1020230136794`, `1020230132022`의 **공식 제1항 텍스트** 차이를 확인한다.
* 기존과 다른 구성요소가 차량·센서·제어 알고리즘에서 무엇인지 연구개발 실무자에게 묻는다. 실제 적용 차종·개발 프로젝트·제품·인허가·실증일·실적은 **기업 직접 답변이 필요**하다.
* 비교 검증 전부터 공개된 문헌은 특허 출원 뉴스가 아니다. 네이버/구글·전문지·현대차/기아 IR·기존 동일 기술 회사 발표와 비교한다. 뉴스 검색 결과 0건은 미보도 보증이 아니다.

## 배포

* `scripts/patent_claim_review.py`: 공식 제1항 원문 점검, 일부 동일 출원인 과거 특허와 문구 유사도 대조, 업종별 추가 질의와 기사 검색 결과 레벨 구분.
* `digests/patent_claim_review_latest.json`: 공식 출처를 확보한 경우에만 생성하고 이전 자료 스냅샷 생성시각을 기록한다.
* `patents.html`: 공식 공보와 심층 분석·청구항의 원자료 생성시각이 정확히 맞을 때에만 조사 카드를 렌더링한다.
* `.github/workflows/kipris-patent-hunt.yml`: 본 수집/심층 분석 다음 단계에서 청구항 원문 조회. 추가 월간 API 호출량은 **당일 최대 6개 신규 상세 + 2개 과거 상세/특허** 등으로 제한.
* 청구항 API가 거부될 수 있으며 이 경우 건강한 공개공보 데이터가 소실되지 않도록 `continue-on-error`로 운영한다. 대신 해당 단계가 실패하면 청구항 결과는 생성/갱신하지 않고 화면에 표시하지 않는다.

## 실제 단독 판정

확인된 원문 텍스트 → 실제 기술적 차이(전문가·기업 설명) → 회사 적용·경쟁사 영향의 직접 검증 → 특허패밀리·기존 기사/IR 조사 → 데스킹 검증. 어느 단계도 자동으로 "단독"이라 확정하지 않는다.

API 공식 정보: https://plus.kipris.or.kr/portal/popup/service/DBII_000000000000001/view.do


## 2026-10-13 실제 API 청구항 원문 검증

- GitHub Actions `38296759483`: KIPRIS 서지상세 `getBibliographyDetailInfoSearch` 정상 수신. 공개 공보 6건의 제1항을 공식 출원번호·청구항 본문과 대조해 확인, 과거 동일 제목·일부 동일 출원인 제1항 2건과 문구 직접 비교 성공.
- 현재 공개번호 `1020260138678` / 공식 출원번호 `1020250031168`; 과거 공개번호 `1020230136794` / 출원번호 `1020220033608`; 과거 공개번호 `1020230132022` / 출원번호 `1020220028944`.
- 공식 청구항 1의 문구 유사도는 두 과거 문헌 대비 각각 0.327. **문구상 다름**까지만 의미한다. 해당 특허가 특정 인지/주행 기능을 최초 발명했거나 최신 자율주행 시스템에 상용화됐음을 뜻하지 않는다.
- 실원문 차이를 취재에 활용하기 위해 문자 비교에서 길이 있는 다른 구간의 **실제 현재/과거 청구항 발췌 최대 2개**를 추출한다. 이는 기계적으로 정렬한 부분 문구이며 청구항의 기술적 차별 구성이 확정된 것이 아니다.
- 언론 기보도 검토 검색은 공동출원인 중 하나 이상을 OR로 검색해 회사명 `기아/현대자동차`를 잘못 단일 키워드로 처리하던 오류를 수정했다.
- 기업 직접 확인: 청구항에서 차이로 나타나는 구절의 실제 기술효과, 기존과 다른 시스템 작동 조건, 적용 차종/제조라인/개발 단계, 해당 사실에 관한 종전 보도가 있는가?
