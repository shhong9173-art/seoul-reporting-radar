# 해외 자동차 뉴스 번역/수집 병목 개선 — 2026-10-16

이전 global_collector.py는 12개 해외 RSS 검색을 순차적으로 수행하며, **각 검색에 등장한 모든 기사 제목과 요약을 중복 제거 전에** 번역했다. Google 번역 호출이 지연/실패하면 제목+요약에 대해 여러 번 재시도했고 원천 수집 실행이 길어졌다. 재수집마다 이미 번역한 기사를 다시 번역하는 문제도 있었다.

## 변경
1. 해외 RSS 12개 검색을 최대 3개 동시 요청으로 제한하고, 기존 회사·산업·시의성 점수 기준을 그대로 적용한다.
2. 모든 출처에서 수집한 기사 제목의 공백·대소문자를 정규화하여 **번역 전 중복 제거**한다. 동명인 경우 최신 공표 데이터를 우선한다.
3. 기존 점수에 따라 최대 32개 기사만 번역한다. 이 숫자는 공개기사 취재 우선순위에만 영향을 주고 시장에 새 뉴스가 없다고 뜻하지 않는다.
4. 기존 global.json 번역은 **원 URL·제목·기사 요약 세 가지가 정확히 같고 기존 번역 상태가 성공인 경우**에만 재사용한다. 다른 사건의 같은 브랜드/기사 제목을 기계적으로 동일 기사로 합치지 않도록 원문·요약 일치를 확인한다.
5. 번역 요청은 최대 동시 3개. 실패한 영어 제목은 한국어 번역으로 표시하지 않고 건너뛰며, 제목 성공/요약 실패는 제목만 한국어로 유지하고 요약 번역 실패를 별도로 표시한다.
6. 해외 12개 RSS별 성공·오류·유효 항목 수·응답 지연을 비밀 없이 글로벌 건강 JSON에 기록하고, 실패해도 기존 global.json/data.json/data.js를 덮어쓰지 않는다.
7. GitHub Actions의 always 단계에서 RSS 진단 두 개만 별도 저장할 수 있다. 이 진단 파일에는 전체 RSS URL, 기사 원문, 토큰이 없다. CI는 병렬 worker 상한과 중복 제목 제거·캐시 동일성·번역 실패 게이트를 오프라인으로 검증한다.

## 해석 원칙
RSS 색인에서 기사를 발견했더라도 단독/기보도 여부가 확인된 게 아니다. 기존 논리의 globalPitch 점수는 후속 검토 단서로만 취급한다. 기존 보도 전문, 기업이 공개 가능한 사실 및 관할 정부 원자료를 별도 확인한다.
