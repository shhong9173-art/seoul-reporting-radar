# DART 'II. 사업의 내용' 공식 원문 비교 시범판

## 목표
- 선배가 활용한 동일회사 시계열 자료 간 재분석 방식을 자동화하되, 표 범위와 단위가 달라진 것을 자동 수치 변화로 단정하지 않는다.
- 첫 시범 범위는 직접 출입처 **HD현대일렉트릭·LS일렉트릭·효성중공업**, 2024년과 2025년 사업보고서.
- `list.json`에서 발행 법인 고유번호, 연간 보고서 표제(`사업보고서 (YYYY.12)`), 정확한 접수번호를 확인한다. 정정보고서가 같은 해에 존재하면 조회 시점 최신 접수를 선택한다.
- `document.xml`의 ZIP을 안전 크기 상한에서 해독해 **`II. 사업의 내용`** 제목이 있는 최상위 문단만 추출한다. 다른 장의 키워드가 섞이지 않도록 한다.
- `수주잔고`, `생산능력`, `가동률`, `사업·제품별 매출` 관련 표에서 명시된 단위와 원문 셀을 발췌해 원문 링크를 보존한다.
- 회사별 이전·당해년도에 같은 주제 표가 하나씩 있고 명시 단위가 일치하면 '양쪽 원문을 비교할 후보'로 표시한다. **표의 품목·계약·회계범위·생산단위가 같다는 추가 증명이 없으면 증감률과 기사를 만들지 않는다.**
- 실패 시 API 상태/표 누락 상태를 구분한다. 출처 확인 전 AI 추정치·당일 기사를 생성하지 않는다.

## 파일
- `scripts/business_content.py`: 공식 사업보고서 2개년 수집·분류·표 증거 발췌, JSON 출력.
- `digests/business_content_latest.json`: 자동 수집 결과 (실제 성공 후 생성).
- `data-lab.html`: 사업내용 원문 비교 패널. 기존 재무 비교 및 단독 레이더에 영향을 주지 않는다.
- `.github/workflows/business-content-scout.yml`: 매주 목요일 오전 7:35 KST 실행, 소스 변경 시 자동 실행 및 수동 실행 가능.
- `tests/test_business_content.py`: 범위·동일 법인·연도·스팬·단위·원문 일치 검증. 외부 네트워크 없음.

## 한계
- 모든 회사는 표양식·문서 구조가 다르다. 보고서 구조가 변경된 경우 자동 원문 증거 추출이 실패할 수 있다.
- 현재 스키마는 표의 일부 행을 표시한다. **수주잔고 금액 변화의 검증된 자동 계산 기능은 아직 없다.**
- 2025년 공시라는 사실만으로 오늘의 미보도 단독이 성립하지 않는다.
- 신규 투자·생산능력·수주잔고에 의미 있는 변화가 확인되어도 사업 영향을 입증하고 동일 사건 선행보도를 점검해야 한다.
- AI 관계자 멘트·확인되지 않은 공급관계·수출 영향은 만들지 않는다.

## 다음 개발
1. 실제 3사 원문의 표 형식을 확인한 뒤 표별 품목·수량·기간·단위 정규화 및 동일 사업부 매핑. 검증된 범위에서만 증감액 계산.
2. 현재 시점 최신 반기/분기 및 매 보고서 갱신으로 변경 빈도 확대.
3. 자동차와 철강·비철 출입처로 확장 (기업별 표 레이아웃 테스트 작성 후).
4. 관세청 HS 원표의 수출액·중량·단가와 회사 사업내용을 **일단 별도 출처로 제시**, 직접 관련성 입증 후 연결.
5. 기존 기사 동일사건 검색 범위 및 회사 질문지, 사용자 취재·데스킹 피드백 축적.
