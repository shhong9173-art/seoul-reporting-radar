## 이번 수정

1. **이름만 같은 임원 연결 차단:** 이름·유효한 전체 출생연월(YYYYMM)이 없으면 다른 회사 명단과의 겸직 교차 확인을 A 근거로 사용하지 않음. 이것만으로 동일 인물이나 법정 결격을 확정하는 것은 아님.
2. **오탐 제거 후 과거 알림 재노출 방지:** 매 실행마다 현재 인물·표시와 과거 이벤트를 다시 대조. 현재 근거(active), 현재 규칙에서 제외(inactive), 확인 불가(unconfirmed)를 구분. 기록은 보존하고 오늘 레이더에는 active만 전달. 조회 실패를 문제 해소로 처리하지 않음. 예전 이름·출생연도만 있는 이벤트가 여러 사람에 걸리면 미확인.
3. **검색 일부 실패·예산 소진 진단:** 인물당 회사·과거 기관 질의를 모두 마쳤을 때만 마지막 성공 시간을 갱신. 실패·중간 예산 소진은 다음 실행에 재시도하며 과거 기사를 현재 확인한 A 근거로 재사용하지 않음.
4. **운영 전송 확인:** 기자 전용 저장소 전송이 HTTP 200이 아니면 실행 실패 처리. 공개 로그에는 현재/과거/미확인 이벤트 건수만 남김.

## 검증

- Python 209개 통과: 임원 점검·임원 명단·타사 임원·레이더 보도 대조·단독 심사·기존 공식 수집기.

- 새 회귀 사례: 출생연월 없음·연도만 존재·잘못된 월, 일부 질의 실패 후 양성 결과, 한 사람 조회 도중 예산 소진, 새 규칙으로 사라진 논란 표시, 명단 조회 실패, 예전 이벤트의 동명이인 모호성.
- 실제 임원 원자료·기사 검색 및 저장소 갱신은 병합 후 기존 보안 설정의 Actions에서 검증한다. 로컬에 API 키를 복사하지 않는다.
