# 사건 혼동 및 LS 표 분류 수정

## 확인된 원인

- 고려아연 20261023801005의 사건번호는 **2025가합10683**, 원고는 한국기업투자홀딩스다. 별도 사건인 **2024가합107981**의 영풍 자기주식 취득 소송과 동일 사건으로 묶으면 안 된다. 기존 테스트는 일반적인 주주대표소송 기사 연결을 정답으로 인정했다.
- LS 2025·2026 반기보고서의 생산능력 표 앞에는 다른 회사의 `생산실적/회수율` 각주가 있다. 최근 키워드 우선 분류가 이 각주를 표 제목으로 오인했다. 접수번호만 비교하는 캐시 때문에 파서 변경도 반영되지 않을 수 있었다.

## 수정 및 검증

- 소송 원문 확인을 검색 앞으로 이동. 사건번호·원고 기반 질의, 다른 사건번호 제외, 일반 소송 기사만 발견하면 미확인. 같은 이름의 별도 소송은 접수 URL별로 유지.
- 표 밖 소제목 상태와 표 대상 법인 보존. 각주 제외, 모호한 복합 제목 제외, 법인이 다른 행 비교 금지. 추출 버전이 없는 캐시는 재사용하지 않음.
- 공식 HTML에서 LS 생산 관련 표를 다시 추출해 운영 스냅샷 교정. 다른 회사 자료와 LS 비생산 표는 보존. 이후 전체 수집은 새 버전으로 다시 실행.
- LS이모빌리티솔루션 EV-Relay, 단위 **백만원**: 생산능력 17,159→25,579 (**49.07%**), 생산실적 14,200→20,217 (**42.37%**). 실물 생산량 증가나 새 단독 후보로 해석하지 않음. 2026-08-14 공시라는 날짜 유지.
- 실제 공식 표를 발췌한 오프라인 fixture 2개와 사건번호·다중사건 기사·원문 실패·구버전 캐시 테스트 추가. 첫 217개 회귀 테스트 통과 후 날짜 오인식 방지 테스트 추가.
- 자동 수집 완료 시 수치 비교·발제 JSON도 재생성하고 화면용 도구 JSON 갱신을 연결.

## 한계

검색 결과 요약문에 사건번호·원고가 없으면 동일 사건 여부를 확정하지 않는다. 기사 전문 확인과 최종 기사 판단은 별도다. 표 발췌 범위 밖의 숫자 및 금액 지표의 물량·가격 분해는 이번 수정으로 검증되지 않는다. PR·운영 실행 결과는 실제 확인 후 별도로 보고한다.
