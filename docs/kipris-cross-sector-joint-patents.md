# 출입처 외 공동출원·순환소재 특허 취재 규칙 (2026-10-13)

## 취재 목적
CJ 등 다른 산업의 회사, 대학·산학협력단, 연구소와 자동차/산업부 출입처가 함께 이름을 올린 공개특허에서 취재 단서를 찾는다. 이용자가 제시한 폐차 플라스틱 효소 재활용 사례와 같은 **분야 연결**을 찾는 기능이며, 해당 사례의 특정 특허번호·실제 공동출원 여부를 이 코드만으로 확인했다고 주장하지 않는다.

## 원문 판정과 제한
1. 기존 KIPRISPlus 승인 ServiceKey로 담당 출입처 24개 법인의 최근 35일 공개특허를 검색한다. 공개된 **전체 출원인** 명단을 보존한다.
2. 공개번호 기준 중복 제거. `outsideBeatCoApplicants`는 공식 출원인 중 24개 출입처 법인의 알려진 법인명과 일치하지 않는 **명칭**을 추출한다. 동일 그룹 회사와 다른 기업/대학을 구분한다. 이름이 다르다는 것만으로 타 산업 소속이나 공동사업 계약이 증명되는 것은 아니다.
3. `순환소재·폐차재활용` 주제는 효소, 해중합, PET, 플라스틱, 재생원료, 폐차 등의 **초록·제목 키워드**로만 탐색한다. 없다는 이유로 원문에 기술이 없다고 단정하지 않는다.
4. `partnerInvestigations`는 출입처 외 명의가 있는 공개특허를 독립 목록으로 보여주되, `confirmedScoops`는 0건. 우선순위 점수는 기자가 검증할 순서일 뿐 **혁신성/독점 가능성**을 의미하지 않는다.
5. 기업/대학 측에서 실제 역할(효소 연구·소재 회수·차량부품 설계 등), 청구항의 기술 범위, 개발 단계, 폐차 재료 투입·재생 소재 적용 범위, 양산 일정, 계약 여부를 확인한다. 최초인지/미보도인지에는 기존 KIPRIS 유사 특허·특허패밀리·보도/IR을 별도 확인한다.

## 누락을 막기 위한 추가 과제
현재 수집은 **기존 기술 키워드로 걸러진 공개특허**를 대상으로 하며, 키워드와 무관한 신규 산업 융합 가능성을 전수 탐지하지 않는다. 과거 35일보다 오래전에 공개된 문헌이나 다른 기관이 단독으로 출원한 문헌 역시 이 화면의 자동 수집 범위 밖이다. 24개 법인 쿼리의 원자료 전수 보존 및 날짜 범위 확장은 호출량/데이터 비용 및 페이지 단위 테스트 후 후속 구축한다.

## 기대 테스트
- 현대차·기아·CJ 공동출원이면서 플라스틱·효소 주제가 있는 가상 API 테스트 자료 → 외부 공동출원인과 주제 표시
- 현대차·기아만 있는 공동출원 → 외부 상대 목록 미표시
- 출원인 법인명 공백 차이 → 다른 법인으로 오분류하지 않음
- 공개특허는 단독·사업화 여부를 자동 확정하지 않음
