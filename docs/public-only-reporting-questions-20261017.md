# 기업 홍보팀에 답변 가능한 사실 질문만 생성 (2026-10-17)

## 문제
기존 단독 레이더는 출입처 기업에 비공개 생산·조달·공급망 변경, 미래 양산 일정, 최종 고객과 같은 실제 답변 불가능한 질문을 자동 추천했다. 2026년 10월 15일 현대차·기아 홍보팀은 미확정 내부 공급망·생산/조달 계획은 대외 답변이 어렵다고 밝혔다. 기자가 실제 기사에 사용할 확인된 답을 확보하기 어렵다.

## 개선
- 단독 후보 종류별 질문 3개 및 선행 취재 단서별 질문 2~3개를 공식 원자료·기공개 공시·정부 등록·결정문·선행 언론기사 전문을 대조하는 문장으로 전면 교체한다.
- 자동차 리콜은 공식 캠페인 번호·차종·연식·시정조치 및 국내 동일 부품 문서, 계약은 공시 접수번호·계약상대·계열관계·사업명·확정 금액, 특허는 공개번호·청구항·공동출원인에 집중.
- 공개 증거로 생산 실적이 확인되는지 확인할 수는 있지만 공개되지 않은 양산 계획, 미래 조달계획, 내부 전략 판단을 요청하지 않는다.
- DART 접수번호를 출력할 때는 정확한 공개 14자리 형식만 삽입하고 회사 내부 데이터는 입력하지 않는다.
- 모든 신규 후보에 publicAnswerableQuestionsOnly=true, internalFutureStrategyRequested=false 상태를 기록한다. 질문 0건이 단독 없음/기사 불가를 의미하지 않는다.
- CI에서 모든 취재 종류·구분의 질문과 실제 Scoop Radar 입력 경로를 검사한다.
