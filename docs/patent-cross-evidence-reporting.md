# 특허 발제 × DART 근거 교차검증 및 취재 결과 관리

## 목적
KIPRIS 최근 35일 공개특허의 발제 후보와 DART 사업내용(7개사), 공식 계약 공시(직접 출입처 일부 21일), 검증된 투자계획 변경(일부 7개사)을 회사명과 기술 용어 기준으로 **교차 조회**한다. 자동 결과는 근거 검토 단서이며, 특정 특허가 실제 해당 사업에 적용됐음을 확인하지 않는다.

## 공식 자료 연동 범위
- scripts/patent_cross_evidence.py는 저장소의 digests/patent_desk_latest.json 및 digests/recent_business_latest.json, digests/recent_contracts_latest.json, digests/investigation_hunt_latest.json을 사용한다.
- 동일 **직접 출입처 법인** 확인 + 특허 제목/공식 초록에서 추출한 **특징적 기술 용어**가 DART 자료의 동일 행·사업명에 나타난 경우에만 근거 링크를 생성한다. 일반 '센서·공정·배터리·냉각' 정도의 광범위 용어는 연결 증거로 사용하지 않는다.
- 관련 수치의 해석, 실제 사업명 동일성, 기술의 상용화, 국내 최초·세계 최초, 수주나 생산량 증감 인과관계는 자동 결론에 포함하지 않는다.
- 같은 회사라도 자회사·계열사 사업을 법인 동일성으로 간주하지 않는다. 원문 공시접수번호와 기술 어휘가 맞지 않으면 빈 결과로 둔다.
- DART 자료가 없어도 가짜 0건의 단독·실적을 만들지 않는다. KIPRIS 원천 수집 자체의 정상 여부와 DART 선택적 교차점검의 실행 상태는 분리된다.
- **NTIS 연구과제·IR·해외 규제와 특허의 동일 사업 자동 매칭은 아직 구현되지 않았다.** 이 자료들이 존재하는 것처럼 표시하지 않는다.

## 기자 확인 5항목
1. 기보도·회사 공식 발표 원문 대조 (prior_coverage)
2. 회사 공식 답변 확인 (company_response)
3. 해당 기술의 실제 제품·공정 적용 확인 (actual_application)
4. 구체적인 산업 영향·효과 수치 근거 확인 (industry_impact)
5. 기사 야마와 반론 확인 (reporting_angle)

발제 화면의 체크 상태는 브라우저 localStorage에만 저장된다. **이 상태는 검증된 회사 인터뷰를 자동 인증하지 않는다.** 브라우저/컴퓨터 공유 및 데이터 삭제 가능성을 고려해 취재원 신원, 비공개 취재 내역, 연락처, 미공개 단독 정보를 입력할 수 있는 메모 필드는 제공하지 않는다. 구체적 내용은 본인의 안전한 편집 시스템에서 관리한다.

## 공개 문서로 확인한 경우
- GitHub Actions의 Record Patent Public Fact Check → Run workflow.
- 공개특허 번호 / 확인한 쟁점 / verified_public, contradicted_public 또는 needs_check / 공개 HTTPS 근거 URL.
- verified_public 및 contradicted_public은 **공개 문서 URL 필수**, needs_check는 URL 없어도 된다. 출고 및 단독 자동 확정은 없다.
- data/patent_reporting_checks.json에 인증된 입력자의 판정을 **추가 이벤트**로 저장한다. 같은 공개번호/검증 유형에서는 가장 최근 이벤트를 사용한다. 민감한 취재 문구는 저장할 수 없다.
- 공개 URL이 있다고 해서 내용 동일성이나 실제 사업 적용이 자동 검증된 것은 아니다. 최종 기사 보고·출고는 기자와 편집자가 별도 판단한다.

## 화면
- patent-pitches.html에서 기존 기자 보고양식(제목 + 3개 항목)은 그대로 유지.
- 발제 카드의 'DART 교차검증 · 기자 취재 결과 체크'에서 공식 DART 링크와 5개 취재확인 상태 확인·수정·복사 가능.
- 교차검증 결과가 최신 특허 발제 원자료의 생성 시각과 다른 경우에는 **시점 불일치/미검증**으로 표기하고 과거 DART 결과를 현재 사업 연계로 주장하지 않는다.
- 연구근거 충분 여부와 발제 검토 가능 여부는 자동 '출고 가능' 인증이 아니다.
