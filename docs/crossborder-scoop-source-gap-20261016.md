# 실제 단독 취재 사례 기반 공식 원문 교차검증 조사서

## 사용자 제시 단독 기사 발굴 유형 (2026-10-16)

1. **미국의 제네시스 리콜과 국내 자동차 리콜/동일 부품/국내 조치 사이의 확인되지 않은 차이**. 특히 2015–2016 현대 제네시스 및 2017–2020 제네시스 G80 차량의 미국 NHTSA 리콜 캠페인 `26V664000`. 미국에서 공식 리콜했다는 사실은 이미 공개된 자료이다. 국내 리콜이 없다는 뜻이나 국내에서 같은 화재가 발생했다는 뜻이 아니다.
2. **현대차 체코 생산법인·기아 슬로바키아 생산법인의 현지 자금배당**, 원문에서 실제 배당·회계인식·본사 현금 수령·배당 재원 이익연도·현지 법인 공시와 국내 선행 보도를 비교해야 한다. 특히 기아 DART 2026-09-16 반기보고서 `20260916000427`의 주석 문장에 개별 법인 **Kia Slovakia s.r.o.(KaSK)로부터 인식한 1,610,458백만원**이라는 회계상 배당수익이 명시돼 있다. 이는 **공시상 인식한 배당수익**이지 그 금액의 현금이 국내로 송금됐다는 증거가 아니다.

## 실제로 보완한 기능

- `scripts/dart_foreign_dividend_watch.py`에 회사명 + `당반기/전반기 배당금수익은` + `법인으로부터 인식한 숫자백만원`이 **같은 문장**에서 연결될 때만 정확한 법인·단위·기간·금액을 기록한다. 이전에는 1건이 단지 `text_proximity_only_not_same_verified_table`였기 때문에 중요 수치를 놓쳤지만, 그 텍스트 자체에서 정확한 주석 문장을 확인 가능하다. 배당 총액과 특정 자회사액을 혼동하지 않고, 같은 법인·기간에 서로 충돌하는 값이면 자동 확정하지 않는다.
- `scripts/crossborder_source_gap_triage.py`는 공식 NHTSA 전체 연식 리콜 원문과 DART 해외 자회사 배당 주석을 교차 취재 조사서로 묶는다. 두 단독 유형 각각에 대해 '미국/한국 확인증거', '국내 실제 동일 부품 여부', '국내 리콜 이력 및 사고/조치', '현지 감사 재무제표·결의서', '언론 선행기사 전문', '회사에 공개 확인 가능한 질문' 항목을 분리한다.
- `crossborder-scoops.html` 상단에 ‘해외 공식 사실 → 국내/현지 비교 → 기보도 → 기사 가치’ 카드 추가. 지금까지의 NHTSA 전체 연식 수집 및 해외 DART 원문은 아래에 계속 보존한다.
- 평일 09:10 KST `crossborder-source-gap.yml`이 이미 수집된 공식 최신 저장 데이터를 사용해 조사서를 `digests/crossborder_source_gap_latest.json`으로 게시한다. **이미 수집된 공식 원천 스냅샷**을 분석하는 방식이므로 NHTSA/국내차량/현지 정부 외부 서비스에 무단 요청을 추가하지 않는다.
- `crossborder-source-gap-ci.yml`은 공식 JSON 스냅샷으로 원문 사실과 미검증 상태를 테스트한다. `confirmedScoops=0`, `approvedArticles=0`, `domesticRecallAbsenceVerified=false`, `foreignParentCashTransferVerified=false`를 확인하지 못하면 배포하지 않는다.

## 이용 가능한 공식 출처와 현 시점의 한계

- NHTSA의 [미국 리콜 공식 캠페인 및 전체 평면 파일](https://www.nhtsa.gov/nhtsa-datasets-and-apis)은 미국 모델·연식·결함/시정 정보를 제공한다. **Part 573 상세 첨부/사고 경위와 국내 동일 부품 여부는 별도 공식 원문 확인이 필요하다.**
- 한국교통안전공단 [자동차리콜센터 리콜현황](https://www.car.go.kr/ri/stat/list.do)을 국내 리콜 확인 출처로 명시한다. [공식 자동차리콜센터 API 안내](https://car.go.kr/rs/cnter/intrcn.do?tabNum=6)는 리콜 정보 API가 **베타이며 사전 협의 필요**라고 안내하므로 미승인 API를 임의 연결하지 않는다. 따라서 한국 리콜 0건 또는 미국과 국내의 미조치 차이를 확정한 적이 없다.
- 체코·슬로바키아 현지 기업등기·감사 재무제표 및 분배결의 원문은 아직 자동 연동되지 않았다. DART 배당수익이 회계상 매출 인식인지 별도/연결 기준인지 먼저 확인하고, 실제 자금 송금 또는 이전 이익연도 초과 배당 같은 주장은 독립 자료를 확보해야 한다.
- 언론 RSS 색인만으로 기사 전문에서 동일한 사건의 국내 적용·배당 금액 보도 여부가 확인되지 않는다. 공시/리콜 그 자체는 이미 공개됐으므로 단독 인정하지 않는다.

## 데스크용 보고 전 반드시 통과할 검증

1. ① 공식 원문에서 무엇이 확정됐는지, ② 국내/현지 원문에서 정확히 같은 범위의 무엇이 확인됐는지, ③ 기존 언론이 해당 차별점을 보도했는지, ④ 기업이 실제로 공개 확인할 수 있는 영향·조치가 있는지.
2. 위 항목이 **모두 취재로 검증되기 전에는** ‘국내 리콜 없다’, ‘해외 배당금 국내로 1조6104억원 회수’, ‘기보도 없는 단독’ 같은 야마를 자동 작성하거나 출고하지 않는다.
3. 부장 보고 형식 `*제목 (홍성효, HH:MM)` + 3개 포인트는 위 검증 완료 후에만 생성한다. 근거가 부족한 이번 조사서는 '후속 원문·회사 확인 대기열'에 한정한다.
