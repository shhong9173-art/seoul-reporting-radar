# 회사별 2개년 사업보고서 동일 수치 검증

## 현장 데이터 확인
- 2026-10-13 01:17 KST 수집: 전력기기 3개사의 2024·2025 사업보고서 본문 모두 확보. 기존 파서는 수동 비교 후보표 3쌍을 확보했지만, 제목 키워드와 단위만 일치하는 표를 서로 묶는 오류 가능성도 관측했다.
- HD현대일렉트릭 2024년도 전력기기 매출(제품군 기준)은 2,035,525백만원이며, 2025년도 사업보고서의 동일 2024년도 열에도 2,035,525백만원으로 나타난다. 2025년 값은 2,835,195백만원. 단순 원시 변화는 +799,670백만원. 이것은 이미 공개된 과거 연간 사업보고서 수치로 **단독 아님**. 신사업·수주 영향은 별도 취재 필요.
- 효성중공업의 중공업부문 '주요 제품 생산능력' 2024년 보고서 2,540,371백만원, 2025년 보고서 2024년 값 역시 2,540,371백만원, 2025년 값 3,128,398백만원. 이는 **백만원 단위의 생산능력 환산 금액**이지 변압기 물리적 생산대수나 MVA가 아니다. 회사 취재 없이 실제 물량 확대·원인을 단정하지 않는다.
- LS일렉트릭은 사업장별 여러 표가 있으므로 사업장/품목 정의와 수치 열 구조가 일치하는 경우만 비교한다. 표의 rowspan/colspan으로 셀 수가 다른 자료는 자동 증감 계산 금지.

## 검산 5단계
1. 같은 회사의 서로 다른 두 해 공식 사업보고서 접수번호가 각각 유효.
2. 해당 표의 주제, 세부 제목(주요 제품군별 등), 표시 단위가 일치. 백만원·USD·톤 등 혼합 표는 제외.
3. 회사/사업장/제품처럼 숫자열 앞에 쓰인 전체 행 식별값이 동일하고, 기간 헤더와 데이터 열 수가 일치.
4. 2025년 보고서의 전기(2024년) 값이 2024년 보고서의 당기 값과 정확히 동일하고, 기수도 연속된 경우만 허용.
5. 중복되는 식별행·여러 표 후보가 있으면 해당 수치를 제거, 원문 대조 및 회사 취재 필요 상태로 유지.

## 출력·확장
- `scripts/business_metric_compare.py`는 `digests/business_content_latest.json`을 읽고 `digests/business_metrics_latest.json`을 만든다.
- `data-lab.html`은 두 JSON의 `generatedAt`과 `sourceGeneratedAt`이 같지 않으면 검산 결과를 숨긴다.
- 사업내용 원문 발굴 대상은 전력기기 3사에서 현대차·기아·현대제철·세아제강 4개사를 추가한 총 7개사로 확장. 회사별 원문 형식이 같다고 가정하지 않는다.
- 결과의 `changePercent`는 공식 공시의 같은 행 수치 간 증감이며, 직접 계약/수주가 새로 발생한 사실이나 신규 단독을 뜻하지 않는다.
- 생산능력 금액과 실제 물리 생산량, 수주잔고, 매출, 관세청 수출액은 서로 다른 변수로 처리한다.

## 남은 과제
- 최신 분기·반기 2026 사업내용과 사업장 투자 현황의 증분 수집.
- 자동 보도검색에서 **동일 사건** 검증을 강화: 원문 프로젝트명·특허/사업부·계약번호·발표일과 기존 기사 매칭.
- 관세청 API 공식 HS/국가/월별 금액·중량·단가 데이터의 3~5년 비교 및 사업부 직접 관련성 별도 검증.
- 기자가 직접 수집한 회사 답변과 부장 데스킹 여부를 저장하는 검증/피드백 절차.
- 아직 공개되지 않은 단독을 탐지했다고 주장하려면 공식 원자료의 신규 사실, 비교 모수, 선행 언론 미보도 여부, 회사 직접 답변까지 확인해야 한다.


## 자동 기존 보도 후보 교차 확인
- `scripts/business_coverage.py`는 2개년 원공시 수치 검산에 통과한 항목에 한해서만 Google News RSS 최근 365일(최대 8검색·항목별 4기사)의 관련 보도 후보를 요청한다.
- 뉴스 검색어·검색 시각·원문 링크·조회 실패를 `digests/business_coverage_latest.json`에 남긴다. `data-lab.html`은 수치 검산 JSON과 생성 시각이 같을 때만 결과를 표시한다.
- Google RSS는 전문지/유료매체 전체를 포함하지 않으며 구체적 숫자·계약·제품 동일성을 자체 입증하지 못한다. 결과 0건, 장애, 검색어 모호함을 독점 보도 근거로 삼지 않는다.
- 확인 상태는 모든 항목에서 `단독 판단 보류`이며, 취재 질문/기존 데스킹 기준과 회사 직접 답변을 통과한 뒤에만 실제 발제할 수 있다.


## 무역통계 추가와 선행보도 검색 보완
- 출입처 원문 수치 변화에 대한 기보도 검색은 특정 기업에 여러 건 검색이 집중되지 않도록 회사별 라운드로빈·주제 중요도를 반영하고, 법인명 50자 이상이 검색어를 오염시키지 않게 단축한다.
- 관세청 `CUSTOMS_API_KEY`가 GitHub Secrets에 없을 때는 공식 통계 최신화를 자동 실행하지 않고 화면에 미연결 상태를 표시한다.
- 관세청 HS4 코드 8504·8544·8703·7208은 광범위한 품목군이므로 각 기업의 수출·수주 실적과 동치가 아니다. 관세청 수출단가는 선적 신고 수출액/중량일 뿐 계약가격이 아니다.
- 관세청 API 필드 누락·월 형식 오류·이상한 금액을 0으로 간주하는 기존 결함을 수정하고 테스트를 붙였다.
