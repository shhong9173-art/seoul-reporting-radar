# 자동차 뉴스 RSS 수집 장애 진단 (2026-10-16)

### 운영 사고
Auto Desk News Update 작업이 2026-10-16 오후에 collector.py의 "collection returned only 0 items"로 실패했다. 기존 수집기는 모든 Google News RSS 파싱/네트워크 예외를 숨기고 빈 목록으로 돌려주어 **원천 장애와 최근 기사 0건을 구분할 수 없었다**. 원래 10건 미만이면 data.js/data.json을 갱신하지 않는 Fail-closed 보호는 적절하므로 유지한다.

### 변경
- 11개 국내 자동차 주제 RSS + 8개 해외 지정 출처 RSS 각각에 대해 확인된 최근 항목 건수, 정상 빈 결과, 통신/파싱 실패를 분리해 기록한다.
- 키·전체 요청 URL·RSS 기사 내용 및 개인정보는 로그/진단 파일에 저장하지 않는다. 오류 형식 이름만 표기한다.
- 데이터가 10건 미만이거나 원천이 실패해도 digests/auto_news_feed_health_latest.json은 별도 생성된다. newsDatasetApprovedForPublish=false는 기존 기사 데이터 갱신 실패를 나타내며, 시장 신규 사건 0건의 증거가 아니다.
- GitHub Actions의 최종 always 단계가 이 건강 상태 파일만 별도 게시한다. 실패한 기사 수집물은 게시하지 않는다. 건강 상태만 저장하는 커밋에는 [skip ci]를 붙이고 자기 자신 재실행을 막는다.
- 주말발제 화면은 최근 뉴스 수집 실패 상태 및 RSS 원천 오류 수를 보여준다. GitHub Pages 배포 자체는 최신 기사 수집/검증이 정상 완료된 경우에만 진행하므로, 배포된 웹페이지에는 이전 정상 스냅샷이 있을 수 있다. 정확한 최신 오류 시각은 GitHub 건강 JSON 및 Actions 참조.

- 정상 파싱 결과가 최근 72시간 0건: 통신 오류 0건과 기사 데이터 미달 상태를 구분.
- 정상 수집: 성공 상태.
