# DART 정정공시 전후 기재와 원공시 독립 대조의 구분

2026년 10월 15일 기준 13개 출입처 기업의 21일 공개 DART 목록에서 정정공시 4건은 원공시 접수번호를 명시적으로 확인하지 못했습니다. 같은 날짜·유사 제목의 DART 접수는 **원공시라는 보증이 없으며** 원문 연결에 이용하지 않습니다.

## 새로운 증거 수준

1. **정정 신고서 자체 전후 기재**: 공식 OpenDART document.xml의 정정항목/정정 전/정정 후 표에서 계약금액·계약기간·생산일정·생산능력·상대방 관련 변경 문구를 찾으면 `issuerCorrectionTable`에 기록. `issuer_reported_amendment_table_only`라는 출처수준을 붙이고 **원공시 독립 비교 및 실제 사업 영향은 거짓(false)** 으로 표시. 비정형 표/행 병합·상충하는 동일 항목·법적/형식적 정정만 있으면 '미확인' 처리.
2. **원공시 독립 대조**: 정정문에 명시된 정확한 원공시 접수번호, 동일 기업·사건 유형을 DART list.json에서 확인한 후 원공시 ZIP도 독립 조회. 두 원문 동일 필드에 차이가 있을 때만 `materialFieldChanges`에 `independent_primary_documents` 기록. 유사 날짜/제목 추론 연결 불허.
3. **기보도 검증**: 공개 DART 사건별 Google News 색인 탐색은 제목이 비슷한 기사 후보의 존재를 알려줄 뿐 동일 계약에 관한 기사임을 증명하지 않음. '검색 미발견'은 미보도·단독 증명이 아님. 바뀐 계약조건을 이미 기사로 쓴 적 있는지, 이전 정정문과 같은 문구인지 **기사 전문·DART 이력을 기자가 확인**해야 함.
4. **최근성**: 정정문 자체의 DART 접수일이 현재 한국시간 최근 3일일 때만 최근 정정 검토 후보로 분리. 9월 29일~10월 6일자 과거 정정을 **10월 15일 신규 독점정보로 재포장하지 않음**.

## 원문 비교가 필요한 사항

- 공시의 정정내용 표는 회사의 설명일 수 있음. 정확한 원 계약 상대, 이전 계약액/기간, 계약 집행 효력은 공식 원공시와 정정 공시를 각각 열어 확인.
- 공시의 '정정 전'은 직전 변경 시점과 같을 수 있으며, 최초 계약 체결 때의 수치라고 단정할 수 없음.
- 공시 속 계약금액 변경은 실제 수주·출하·매출 증가와 동일하지 않음. 계열사 거래는 최종 외부 고객과 연결 매출 계상 재확인.
- 회사 홍보팀에 실제 공개·확인 가능한 **이미 발생한** 변경, 대외 공시된 계약 상대/금액/기간을 질문. 비공개 계약 조건·장래 물량 재배치·미확정 내부계획을 묻지 않음.
- 확인된 수정내용과 신규 시점, 회사의 실제 영향, 선행보도 부재를 검증한 뒤에만 야마·발제를 검토. 이 기능은 자동 기사 승인 또는 단독 등급이 아님.

## 자동 점검

`tests/test_dart_issuer_table_review.py`는 원공시 없음에도 issuer-only 전후 설명이 원공시 독립 변경으로 혼합되지 않는지, 정정된 금액·기간/형식적 항목의 구분, 상충값/위조 URL 차단, 13일 초과 오래된 정정 취재 후보가 최근 단독으로 분류되지 않는지 테스트합니다.

실제 4개 정정 원문에서 구조화된 변경 표를 찾았는지는 **병합 후 공식 OpenDART 실제 재수집 JSON**으로 따로 검증합니다. 발견되지 않았으면 새 값을 만들어내거나 '변경 없음'으로 해석하지 않습니다.
