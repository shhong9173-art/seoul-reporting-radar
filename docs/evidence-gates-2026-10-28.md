# 후보 근거 검증과 기보도 오매칭 수정

기준 main: `8ace1311daa61620fefe94f8dcf823718a5bfa33`.

## 재현한 문제

- 운영 MCP의 저장하지 않는 `candidate_check`에 example.com URL, `not-a-real-hash`, 2000-01-01 날짜, 직접 적은 채널 `ok`를 넣자 `추천·100점·단독 확실`을 반환했다. 실제 후보 저장은 하지 않았다.
- `scoop_screen.judge`는 회사명 부분 문자열과 숫자만 일치해도 같은 수치 선행으로 분류했다. 포스코인터내셔널 기사, 포스코의 별개 기부 기사, 2030년 미래 날짜 기사도 오판할 수 있었다.

## 변경

- `cloudflare/evidence.mjs`: 서버가 실제 읽은 URL·전체 본문 해시·명시된 게시일·발췌 구간과 실제 검색 질의·채널 상태·조회 범위·기사 목록을 비공개 검증 기록으로 관리한다. 호출자가 만든 ID는 인정하지 않는다. 유효기간 24시간, 최대 1,000개이며 새 기록 저장 시 만료 기록을 정리한다. 문서 전문은 저장하지 않는다.
- `live_tools.mjs`: 원문·뉴스 도구가 검증 기록 ID를 발급한다. 공개 연결은 조회만 가능하고 기록 발급은 기자 전용이다. DART 틀 페이지 조회 실패는 본문 확인으로 인정하지 않는다. ZIP 검색은 축약하지 않은 전체 해시를 돌려준다. 검색의 잘못된 응답 구조·날짜 누락/미래·최신순 상한·오래된 단독 색인을 실패 또는 일부 조회로 구분한다.
- `scoring.mjs`, `mcp.mjs`, `store.mjs`: 점검과 제출 모두 같은 서버 검증을 거친다. 실제 인용과 숫자, URL·해시·게시일, 기업·사건 낱말이 연결된 서로 다른 검색 2개를 확인한다. 입력한 `ok`나 `단독 확실`은 인증이 아니다. 날짜 미확인·미래·30일 이전 자료와 미검증 파생 계산은 조사대기다. 추천이어도 단독 미확정이며 신규성은 별도 취재가 필요하다.
- `scripts/scoop_screen.py`: 법인명 경계를 확인하고 그룹/계열사 별칭 혼용을 줄였다. 숫자 단독 일치는 판정에서 제외한다. 같은 수치 선행에는 수치 경계·단위·명시적 기간·복수 사건 낱말과 구체적 지명/품목 등을 요구한다. 그 외 관련 보도는 원문 검토 대상으로 남긴다. 날짜 누락·오류·미래는 미확인, 실패 채널의 잔여 항목은 판정 근거에서 제외한다. 채널별 `invalidDates` 진단을 추가했다.

## 사용 변경

기자 전용 연결에서 원문을 조회해 `source_evidence_id`를 받고, 실제 반환 URL·전체 해시·검증 게시일과 직접 인용을 후보에 넣는다. 해석은 `impact`에 구분한다. 기업명과 원문 사건 낱말로 `news_check(days=365)`를 질의 변경해 2번 조회하고 `news_evidence_ids`, `event_terms`를 넣는다. 점검·제출 도구의 스키마에도 이 설명을 반영했다.

게시일을 자동으로 확인하지 못하거나 과거 자료를 새로 분석한 경우, 기존 기사가 검색된 경우에는 조사대기로 남긴다. 이는 단서 삭제가 아니다. 공개 도구만 사용하는 연결에서는 추천 인증을 받을 수 없다. 기존 저장 후보를 소급 삭제하거나 운영 JSON을 변경하지 않았다.

## 로컬 검증

- 공식 수집기 회귀: 105개 통과.
- `test_scoop_screen`, `test_naver_api`, `test_private_store`: 24개 통과.
- MCP와 주소 전환 Node 회귀: 51개 통과.
- 주요 추가 검증: 가짜/만료/다른 원문 기록, 공개 연결의 비공개 기록 접근, 오래된/미래/누락 날짜, 접수 마감일 혼동, 원문에 없는 문장·숫자, 미검증 계산, 같은 검색 기록 재사용, 실제 실패·비정상 응답·오래된 색인·검색 기사 존재, DART 틀 실패/ZIP 성공, 제출 우회 방지, 계열사·별개 사건·다른 단위/기간/숫자 경계.
- 정상 원문·검색 응답을 제공하는 오프라인 종단 테스트에서 추천과 하루 5개 제한이 유지됨을 확인했다. 테스트 자료는 운영 후보로 전송하지 않았다.

## 한계

- 자동 점검은 문장 의미의 진실성·새로움·공급망 영향·기존 기사와의 완전한 사건 동일성을 확정하지 않는다. 검색 0건도 미보도 증거가 아니다.
- 게시일 자동 인식은 명시적 한국어 게시일 라벨, datePublished/발행 메타데이터, DART 접수일만 사용한다. 다른 양식은 미확인으로 남을 수 있다.
- 관련 기사 재검토 승인과 파생 수치의 피연산자·단위 검증은 후속 과제다. 지금은 임의로 통과시키지 않는다.
- 실제 비공개 계정의 추천 제출은 실행하지 않았다. 배포 검증은 PR/Actions 상태와 공개 읽기 전용 점검 결과로 별도 보고한다.
