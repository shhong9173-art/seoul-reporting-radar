# 국내 리콜 공개목록·선행보도 제목 탐색 (2026-10-16)

자동차리콜센터 리콜 API는 현재 베타이며 사전 협의를 거쳐 제공한다: https://car.go.kr/rs/cnter/intrcn.do?tabNum=6. 이 모듈은 **리콜 API를 호출하지 않음**. 공개 웹 리콜현황 화면의 첫 쪽(차종 검색어 G80, 제네시스, 아이오닉9)만 최대 3회 요청하고 Google News RSS의 관련 검색 제목을 최대 2회 받는다. 호스트 제한, 응답 500KB 상한, 12초 제한, 전체 5회 상한.

자동차리콜센터의 검색어 필터가 서버에 적용됐는지/전체 페이지를 읽었는지 미검증이므로 목록에 같은 차종명 제목이 있어도 동일 연식·시트 스위치 부품·결함/시정조치라고 판정하지 않는다. 제목이 0건이어도 국내 리콜 0건이라는 뜻이 아니다. 뉴스 RSS 제목만으로 동일 사안 보도 여부나 미보도 단독을 판정하지 않는다.

데이터 파일: `digests/domestic_recall_screen_latest.json`. `sourceUsSnapshot`이 동일한 NHTSA 수집 시각일 때만 원래 조사서에 연결한다. API 승인 전까지 정확한 부품·차종/연식·국내 실제 리콜/무상수리 여부는 추가 공개자료 또는 취재 확인 사항이다. 단독 확정·발제 승인 0건 원칙 유지.
