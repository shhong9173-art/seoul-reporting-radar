# 서울 취재 레이더

개인 기자용 취재 아이템 대시보드의 무료 정적 웹사이트 프로토타입입니다.

## 현재 포함
- 오늘의 레이더
- S/A/B/추적 취재 필터
- 분야 필터
- 검색
- 기사 가치 점수
- 아이템 상세 취재 질문
- 추가 확인 데이터
- 원문 링크
- 반응형 화면

## 중요한 점
현재 `data.js`에는 실제 자동수집 전의 예시 데이터만 들어 있습니다.
실서비스에서는 서울시와 25개 자치구의 공식 자료 수집기 및 DB를 연결해 `data.js` 또는 API 응답을 자동 갱신해야 합니다.

## 무료 배포
GitHub Pages, Cloudflare Pages 등 정적 호스팅에 올릴 수 있습니다.
