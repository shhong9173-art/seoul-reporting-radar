# 산업부 자동차 취재 레이더

자동차·부품·배터리 담당 기자용 뉴스 모니터링 대시보드입니다.

## 현재 기능
- 오늘 꼭 볼 것 / 단독·속보 후보 / 후속 취재 후보 / 전체 모니터링
- 완성차 / 부품 / 배터리 / 정책·관세 / 중국차 / 노조·생산 분야 필터
- 주요 자동차·배터리 기업 필터
- Google News RSS 기반 최근 72시간 자동 수집
- 기사 제목 기반 중복 제거
- 단독·속보 및 업계 파급 키워드 기반 취재가치 점수
- 취재 포인트와 추가 확인 질문 자동 생성
- 원문 링크만 제공하며 기사 본문을 재게시하지 않는 모니터링 방식

## 자동 갱신
`.github/workflows/auto-desk.yml`이 30분마다 `collector.py`를 실행하고 `data.js`를 갱신합니다. `data.js` 변경은 workflow 재실행 대상에서 제외해 무한 실행을 방지합니다.

## 주의
‘단독 후보’는 제목의 단독·속보 표기를 탐지한 것이며, 실제 단독 여부를 보증하지 않습니다. 기사 작성 전 원문과 취재원 확인이 필요합니다.
