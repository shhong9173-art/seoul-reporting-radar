# 산업부 자동차 취재 레이더

자동차·부품·배터리 담당 기자가 출근 후 먼저 보는 것을 목표로 만든 개인용 뉴스 모니터링 대시보드입니다.

## 화면
- 오늘 꼭 볼 것
- 단독·속보 후보
- 후속 취재 후보
- 전체 모니터링
- 완성차 / 부품 / 배터리 / 정책·관세 / 중국차 / 노조·생산 / 리콜·안전 / 수주·투자
- 주요 기업 필터
- 검색 및 취재가치·최신순·경쟁지 선행순 정렬

## 자동 수집
GitHub Actions가 30분마다 Google News RSS를 수집합니다. 최근 72시간 이내 기사만 대상으로 하며, 자동차판에서 실제로 볼 가치가 높은 검색군을 별도로 구성했습니다.

수집군에는 완성차, 부품, 배터리, 미국 관세·정책, 중국차, 노조·생산, 수주·투자, 리콜·안전, 단독 기사, 미국·글로벌 공급망이 포함됩니다.

## 단독·경쟁지 레이더
기사 제목의 단독·속보 표기를 별도로 감지합니다. 같은 이슈가 여러 매체에서 발견되면 하나의 이슈 클러스터로 묶고, 최초 관측 시각·매체와 확인된 매체 수를 표시합니다.

단, '단독 후보'는 자동 판정 결과이며 실제 독점 취재 여부를 보증하지 않습니다. 기사 작성 전 원문과 취재원 확인이 필요합니다.

## 취재가치 점수
점수는 단독·속보 여부, 산업 파급 키워드, 관련 기업 수, 매체 신뢰도 가중치, 동일 이슈의 확산 정도 등을 조합합니다. 자동 점수는 편집 판단을 대체하지 않고 우선순위 설정용으로만 사용합니다.

## 저작권·운영 원칙
기사 본문을 사이트에 재게시하지 않고 제목, 매체, 발행시각, 짧은 메타 요약, 원문 링크 중심으로 구성합니다.

## 배포
GitHub Pages 등 정적 호스팅에서 사용할 수 있습니다. 데이터는 `data.js`로 공급됩니다.

## 현재 저장소 범위
이 저장소는 서울시·자치구 취재 레이더와 무관하며 자동차·부품·배터리 산업부 레이더 전용입니다.
