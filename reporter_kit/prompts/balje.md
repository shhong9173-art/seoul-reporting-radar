# /balje 실제 부장 데스킹 발제 양식

이 파일은 선배의 `ㅇ제목+5~9개 불릿`보다 기자 본인의 실제 데스킹 양식을 우선한다.

## 필수 출력
`*기사 핵심이 드러나는 제목 (홍성효, HH:MM)`
`- ` 검증된 사실·수치가 들어간 기사 포인트 약 3개

첫 포인트는 현재 변화와 결론. 두 번째는 공식 발표 시점·모수·비교 수치. 세 번째는 기업별 영향·실제 대응과 검증된 전망.

## 작성 규칙
- 부장이 확인하도록 요구한 원자료·실제 기업 영향·회사 직접 답변을 우선한다.
- 한 문장으로 야마가 설명되지 않으면 보고 확정형으로 작성하지 않는다.
- 단순 특허·MOU·리콜·투자 발표 및 정정 공시를 단독감으로 부풀리지 않는다.
- BYD 유럽 판매량 하나로 한국 유입을 단정하지 않는 것처럼, 그럴듯해도 증명되지 않은 인과관계는 빼야 한다.
- 경쟁사 비교는 동일 시점·같은 품목·동일 모수일 때만.
- 확인 전 사실과 실제 회사 답변을 섞지 않는다.
- 기존 기사 출고본에서 학습한 리드, 제목, 기사체를 우선한다.

## 예시(가상, 실제 취재 수치 아님)
*해외 통상 규정 변경에 국내 철강사 부담 갈려…수출 물량별 차이 (홍성효, 10:30)
- ○○ 당국의 신규 규정에서 적용 품목·시행일·예외 조건이 확인됐으며, 한국 수출업체별 대상 범위가 다른 상황
- 공식 원문과 관세청 동일 HS 통계로 실제 적용 대상 물량을 비교하고, 기존 규정 대비 바뀐 조항 확인
- 기업별 구체적 부담과 대응은 취재 결과로 정리. 직접 확인 전 수혜·피해 규모는 기사로 단정하지 않음

발제 뒤에는 별도 검증 메모를 둔다: 원자료 URL·접수번호·발행일·검색한 선행 기사·회사에 확인할 질문 2~3개.

선배 원본은 `senior_balje_reference.md`에 비교 자료로 보존했다.
